# «Открыть в Бересте» для Яндекс Браузера

Кнопка в левом нижнем углу передаёт текущую HTTPS-ссылку Telegram установленной Бересте по нажатию. Для запуска нужен зарегистрированный в Windows обработчик `beresta://`.

## Локальная установка

1. В настольном Яндекс Браузере откройте `browser://extensions` и включите «Режим разработчика».
2. Нажмите «Загрузить распакованное расширение» и выберите папку `browser-extension` с файлом `manifest.json`.
3. Откройте страницу Telegram или обновите уже открытую вкладку. Нажмите «Открыть в Бересте» и подтвердите запуск, если браузер спросит.

## Поддерживаемые ссылки

Кнопка доступна на `t.me`, `telegram.me`, `telegram.dog`, допустимых поддоменах `<username>.t.me` и в Telegram Web по путям `/a`, `/k` и `/z`. В Telegram Web передаются адреса клиента, чата и сообщения. Кнопка скрыта на ссылках авторизации, в том числе при наличии токена входа в адресе. Расширение работает в основной вкладке и не запрашивает доступ к истории, cookies или данным аккаунта.

## Проверка

```powershell
node --check browser-extension/content.js
node --test browser-extension/test/content.test.cjs
```
