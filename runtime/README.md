# Bundled runtime

Tauri packages only the files explicitly listed in `scripts/release-runtime-manifest.json`. A full Windows installation includes media tools, a JavaScript runtime, the offline recognition engine and models. It needs no developer checkout, external Node.js or Python environment, and does not download a speech model on first use.

Relay 1.3.1 builds one generic installer. It inherits the host network configuration and does not import DNS/VPN profiles, bundle internal network engines, create a TUN adapter or change Windows DNS, proxy, routes or Lagom services. Retired network executables and notices may remain in the developer checkout as exact hash-verified legacy assets; the explicit resource mapping excludes them from the new payload. Installer upgrades remove only unchanged legacy runtime files with hashes in `tauri/installer-legacy-runtime.json`, scoped to the selected installation. Modified files, unknown files and account profiles are preserved.

- `node.exe`: Node.js 24.21.0, Windows x64. SHA-256: `ba4e6d110e8c1592a1ecd390f6b05f3da124b13871a5be62b341a07a853c6c32`. License and third-party notices: `NODE-LICENSE.txt` and `licenses/NODE-LICENSE.txt`.
- `yt-dlp.exe`: pinned 2026.08.19 standalone media extractor. Notices: `YT-DLP-LICENSE.txt` and `YT-DLP-THIRD-PARTY-LICENSES.txt`; upstream: https://github.com/yt-dlp/yt-dlp/releases/tag/2026.08.19.
- `media/ffmpeg.exe` and `media/ffprobe.exe`: Gyan FFmpeg 9.0.2 essentials Windows build, for merging video/audio and validating local media. Build/source details: `media/FFMPEG-BUILD-README.txt`; license: `media/FFMPEG-LICENSE.txt`.
- `transcription/`: Whisper.cpp 1.9.4 CPU engine, multilingual `ggml-small-q5_1.bin`, Silero VAD, CPU backends and app-local Microsoft runtime DLLs. Exact upstream revisions, checksums, licenses and the UTF-8 manifest derivation are recorded in `transcription/provenance.json`. Model and DLLs remain application resources, not embedded copies in the Rust executable. Unicode engine paths require Windows 10 version 1903 or later.

Voice recognition runs locally after Telegram supplies the selected audio. It accepts up to 64 MiB and 30 minutes, processes one job at a time and can be cancelled. Temporary audio and worker files are removed on success, error, cancellation and normal exit; startup also removes stale owned jobs. Recognition quality depends on the recording, language, noise and speech clarity. Silence is filtered by the bundled VAD.

Media extraction permits canonical YouTube, Instagram and X publication links and bounded provider/CDN connections using the configured host network. It selects the best available source video and audio without a Relay resolution or recording-duration cap; merging preserves the source streams without re-encoding. Original downloads stream to disk and are saved to Downloads using collision-safe names. Their finite bounds are available disk space, cancellation and worker deadlines. Inline previews and Telegram attachment preparation retain a 64 MiB per-file IPC memory bound and a 128 MiB batch memory bound; Telegram albums contain at most 10 attachments. Original saving uses a separate file-backed route and does not use those memory bounds. Source authentication, embedding restrictions, DRM and unavailable publications can prevent playback or download. Only after an authentication error may X/Instagram use cookies from their exact in-app child WebView; no external browser profiles or YouTube credentials are read. Transient cookie files are owned by the resolver and deleted with its job. Incoming links never send or upload a file automatically.

Runtime changes require updating the reviewed manifest and explicit resource mapping, then rebuilding and verifying the complete installer.
