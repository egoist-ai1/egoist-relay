# Исходный компонент

Производственные модули Egoist Social MCP зафиксированы на коммите `51242e52e04b724e6d29e2ac0d67f5c96bebde76` одноимённого проекта Egoist. В исходном проекте отдельный файл лицензии не указан. Исходные модули и контракт именованного канала приложены рядом.

Сборка «Бересты» использует штатный Windows PowerShell и проверку приватного каталога из `runtime/research/ensure-private-state.ps1`. Путь к EXE и комплекту транскрибации вычисляется относительно установки. Встроенный MCP и его служба предоставляют исследовательские операции чтения и локальные выгрузки.
