# Локальный MCP «Бересты»

Откройте настройки «Бересты», найдите раздел «Локальный MCP» и скопируйте параметры подключения. Вставьте их в настройки выбранного MCP-клиента с транспортом **stdio**. Параметры содержат пути к файлам установленной «Бересты». Они не запускают сервер и не меняют настройки клиента.

Для ручной настройки замените пример пути `C:\Apps\Egoist Relay` на папку установки.

```json
{
  "mcpServers": {
    "beresta": {
      "command": "C:\\Apps\\Egoist Relay\\runtime\\node.exe",
      "args": ["C:\\Apps\\Egoist Relay\\runtime\\research-mcp\\src\\research\\mcp.mjs"]
    }
  }
}
```

Откройте «Бересту» и выполните `social_status` с `include: ["accounts", "capabilities"]`. Сервер использует локальный именованный канал Windows и существующие сессии приложения. Обработчик заявляет реальные возможности каждой платформы. Тексты и выгрузки принадлежат владельцу аккаунта. Личные диалоги Telegram закрыты по умолчанию. Файлы на диске записываются в рабочую папку исследований.

- `social_plan` и `social_run` собирают сообщения и посты, доступные аккаунту.
- `social_records`, `social_stats` и `social_export` работают с собранными данными.
- `social_submit` сохраняет совместимость с прежним чтением и загрузкой вложений в пределах возможностей платформы.

В план можно передать до 200 источников напрямую или файл `.txt`, `.csv` или `.jsonl` в рабочей папке с числом строк до 50 000. Доступные источники и этапы зависят от возможностей провайдера, прав текущего аккаунта и лимитов. Запрашивайте следующие страницы по курсору. Читайте предупреждения о частичных данных и причины отказов из ответа.

Для чтения результатов одного задания задайте `scope.jobIds` в `social_records`, `social_stats` или `social_export`. Для следующей страницы записей или статистики передайте `page.nextCursor` как `cursor` с теми же фильтрами. Для продолжения выгрузки используйте `data.nextCursor` и новый `idempotencyKey`. `scope.accountRef` принимает псевдоним активного аккаунта из `social_status`. При смене аккаунта прежнее задание продолжится после возвращения к его профилю.

Собранные до введения привязки к аккаунту записи сохранены. Для них задайте `scope.legacyArchive: true`, а для просмотра или отмены прежнего задания используйте `legacyArchive: true` на верхнем уровне. Незавершённое задание этого архива можно заменить новым планом, созданным в нужном профиле.

Выдача по заданию содержит первый снимок каждой записи, полученный этим заданием. Общая выдача возвращает первую наблюдавшуюся версию записи в пределах источника. Если прежняя версия «Бересты» отбросила снимок при общей дедупликации, `corpus.gaps` или `data.gaps` отмечает `job_snapshots_deduplicated`. Старые файлы Telegram без подтверждённой политики личных диалогов доступны через UUID только при разрешении `readPrivateThread` владельцем. Изменения `policy.json` применяются без перезапуска.

Имя службы и данные совпадают с отдельной поставкой локального MCP. Если MCP сообщает, что запущенная служба относится к другой сборке дождитесь окончания активных заданий и запустите `runtime/node.exe runtime/research-mcp/scripts/research-service.mjs restart` из папки установки. Запуск «Бересты» из MCP в фоне требует существующего подтверждения установки для точной версии EXE. Открытое приложение использует обычный локальный канал.

Отмена запроса `social_job` завершает ожидание прогресса. Сбор продолжается, и его состояние можно снова проверить по тому же `jobId`. Для остановки сбора используется `social_job_control` с действием `cancel`.

Встроенный MCP предназначен для чтения, поиска и локальных выгрузок. Чтобы начать работу с другого компьютера, запустите MCP-клиент на том же ПК и под тем же пользователем Windows, что и «Береста».
