# Береста

Настольное приложение для Windows с Telegram, X, Instagram, Telegram Mini Apps и локальным исследовательским MCP.

В [BUILDING.md](BUILDING.md) описаны требования к сборке. Для Telegram нужны собственные реквизиты приложения. В [списке зависимостей](dependency-sources.json) отмечены недостающие материалы для распространения Windows-установщика. Этот выпуск содержит исходный код.

Параметры локального MCP копируются из настроек «Бересты». Описание транспорта stdio, источников и выгрузок есть в [руководстве MCP](runtime/research-mcp/README.md).
