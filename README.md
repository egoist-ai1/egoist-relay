# Egoist Relay

**Egoist Relay 1.6.1** — локальное Windows-приложение для Telegram, X и Instagram.

Отдельные WebView2 сохраняют контекст сервисов при переключении. Панель «Загрузки и пересылки» открывается через Ctrl+J и позволяет найти результат сохранения, открыть файл, отменить операцию или безопасно повторить прерванную попытку. Пересылка предлагает «Ссылка / Медиа / Файл», начиная с «Ссылка». Локальный журнал хранится до 30 дней под защитой DPAPI CurrentUser; очистка журнала сохраняет файлы.

Интерфейс использует глубокий чёрный и нейтральный серый. Версия 1.6.1 исправляет прозрачные меню и наложения в списке чатов, а Telegram Mini Apps и дочерние окна используют принадлежащие приложению WebView2 с той же сетевой средой.

## Установка

[Windows x64 — установщик 1.6.1](https://github.com/egoist-ai1/egoist-relay/releases/tag/relay-v1.6.1).
Выпуск предварительный; установщик без цифровой подписи. Автоматическое обновление отключено.

Relay наследует действующую сетевую конфигурацию Windows для WebView2 и не меняет настройки Windows или Lagom. Совместимость конкретного Mini App, PAC и живых аккаунтов требует проверки в вашем окружении.
