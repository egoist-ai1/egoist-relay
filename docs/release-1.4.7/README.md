# Egoist Relay 1.4.7

[Установщик и исходники 1.4.7 опубликованы](https://github.com/egoist-ai1/egoist-relay/releases/tag/relay-v1.4.7) как prerelease. По прямому запросу владельца канонический установщик также обновил рабочую установку 1.4.6 → 1.4.7 без удаления профиля; приложение перезапущено в фоне. [Результат публикации и переустановки](INSTALLATION.md).

## Исправления

- Общий учёт вложенных модальных окон сохраняет открытого родителя, фокус и глобальное состояние диалогов.
- Отложенные переходы отменяются при закрытии и размонтировании; время закрытия согласовано с CSS. Reduced motion отключает движение.
- При увеличении текста диалог ограничен viewport; заголовок имеет доступное имя и подсказку.
- Instagram использует однозначный timestamp permalink. Индекс существующих кнопок заменяет повторный линейный поиск для каждого поста.
- Медиа учитывает один дедлайн от очереди до завершения; отмена и завершение Windows Job предотвращают оставшиеся worker процессы. Проверка Node ограничена двумя секундами на кандидата.
- Сохранены ранее внесённые восстановление Telegram транспорта и безопасный private handoff с ограниченным повтором.
- Source-packaging pipeline также исключает три устаревших файла из публичного архива; обычная подготовка исходников даёт те же 3305 файлов, что и проверенный whitelist.
- Из файлов интерфейса исключены устаревшие отчёты сборки: 100 540 813 исходных байт. Чистый каталог интерфейса — 98 948 717 байт. Предварительный каталог (203 202 121 байт) содержал также устаревшие файлы модулей. Сравнение EXE: 82 075 648 → 77 798 912 байт. Эти числа не означают такое же сокращение памяти или сетевой задержки.

## Пределы готовности

ActiveWebsites остался gated из-за сброса synthetic route. Реальные авторизованные Telegram/X/Instagram, Lagom и внешняя доступность сетей не проверялись. Headless результаты не доказывают native DPI/GPU или 60 fps. WinHTTP PAC сохраняет синхронную фазу; общий дедлайн не прерывает её внутри вызова.

Изолированная упаковка использует отдельную product identity, отключённые protocol registration/shortcuts/bootstrap и тот же EXE/runtime. Рабочая установка отдельно обновлена до 1.4.7; приёмка на чистом устройстве не выполнялась. Установщик и EXE не имеют подписи доверенного издателя. Тест использовал отдельный профиль. Метаданные активного рабочего профиля изменялись и после удаления теста, без его процессов; содержимое профиля не читалось, неизменность его байтов не утверждается.

Полный комплект corresponding source для всех поставляемых зависимостей отсутствует: точные FFmpeg dependency/build inputs и архивы standalone/dependency sources перечислены [inventory исходников](dependency-sources.json). [Поставщик FFmpeg](https://www.gyan.dev/ffmpeg/builds/) подтверждает базовый commit для 9.0.2; это не закрывает недостающий комплект в проекте. Установщик опубликован по прямому запросу владельца. Inventory остаётся неполным; статусы в dependency-sources.json не изменялись, GitHub release сохраняет prerelease.
