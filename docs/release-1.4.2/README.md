# Egoist Relay 1.4.2

Финальная версия объединяет исправление загрузки сервисов, панели управления ботом, поведения видео и исследовательского bridge. Установщик собран, его EXE проверен по точному хешу; изолированные установка, запуск и удаление прошли успешно. Версия 1.4.2 установлена после подтверждённого штатного выхода. Проверены точный EXE и 40 runtime-файлов; аккаунты открыты пользователем. Дополнительный полный аудит со стрессовыми, сценарными и визуальными тестами продолжается по новой задаче.

## Медиа

Встроенные кнопки «Скачать оригинал» сохраняют файл в Downloads через файловый канал. Выбирается лучший доступный источник видео и звука, объединение без перекодирования. Убраны фильтры 720p и 10 минут. Фото X используют оригинальный размер, Instagram — максимальный корректный адрес, наблюдаемый в srcset. Скачивание использует один GET, без обязательного HEAD.

Telegram сохраняет исходные байты файлов. При повторе байты части читаются один раз; отмена и ошибка освобождают занятый слот. Ответ false не считается успешной отправкой. Лимит размера в composer берётся из конфигурации аккаунта; utility потолок 4000 МиБ убран. Протокольные размеры частей сохраняются. [Telegram file API](https://core.telegram.org/api/files) описывает обязательные пределы частей и серверные ожидания; клиент не может устранить ограничения сервиса.

## Интерфейс

Исправлен показанный столбец текста справа в Telegram: глобальный стиль dialog-buttons ограничен диалогом даты, действия бота имеют отдельную вертикальную раскладку. Проверены 240–400px и RTL. Instagram корректно приостанавливает фоновое видео, сохраняет состояние при перестройке DOM и выбирает доступную кнопку истории; X освобождает удалённые video nodes. Ссылка для пересылки относится к выбранному посту.

## Проверки и границы

[validation.json](validation.json) содержит результаты проверок; [capabilities.md](capabilities.md) — фактическую матрицу MCP. [installation.json](installation.json) фиксирует готовый пакет, изолированную проверку и состояние установки. [Review board](review.html) относится к точному [Реестр.json](Реестр.json).

Проверки на локальных данных не измеряют скорость провайдера или серверов. Отправка в личные чаты, покупки, присоединение к группам и изменение аккаунтов не выполнялись. Ограничения доступа аккаунта, challenges, удалённый контент и требования сервиса сохраняются.

Оригиналы идут через диск без фиксированного потолка 64 МиБ. Для предпросмотра в Telegram остаётся bounded IPC frame 64 МиБ, для подготовки пересылки — суммарный буфер 128 МиБ/10 вложений. Для файлов большего размера предусмотрено скачивание оригинала и обычное прикрепление файла в Telegram. Свободное место и конечный срок задания проверяются. MCP direct-CDN job ограничен 1 ГиБ/файл, 2 ГиБ/задание и 500 media IDs; большие подборки продолжаются по проверенным cursor. HLS/DASH доступны файловому resolver выбранного поста; MCP direct downloader не выдаёт неподдерживаемый поток за готовый файл.

При редкой ошибке очистки временного каталога уже сохранённый оригинал может остаться в Downloads, а операция сообщит ошибку; повтор создаёт новый уникальный файл.

Все настройки DNS устройства, DoH, стратегии и исключения Lagom сохраняются. Семь доменов обработки, разрешённых на предыдущем этапе, остаются в действующем hostlist; новые общесистемные изменения не выполнялись.
