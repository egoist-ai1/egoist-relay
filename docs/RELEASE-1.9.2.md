# Egoist Social 1.9.2

13 октября 2026. Правка после установки 1.9.1; остальное — как в [1.9.1](RELEASE-1.9.1.md) и [1.9.0](RELEASE-1.9.0.md).

## Что изменилось

- **Меню скорости воспроизведения:** «0.5X», «0.75X», «1X», «1.5X», «2X» снова в одну строку. Меню сжимается по содержимому, а пункт меню разрешал перенос в любом месте, поэтому значения разваливались по одной букве.

## Разобрано без изменений в коде

- **Нет звука у голосовых в 1.9.1.** В Windows не было активного устройства вывода (все динамики и наушники отключены, `GetDefaultAudioEndpoint` → `ERROR_NOT_FOUND`). Chromium в этом случае воспроизводит без звука, и плеер показывает «пауза/играет». Приложение и туннель ни при чём.

## Проверки

- В браузере (мок-клиент): меню скорости в одну строку, ширина по содержимому.
- `stylelint` изменённого файла — без ошибок; `npm run release:preflight` — пройден.
