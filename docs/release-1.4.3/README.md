# Egoist Relay 1.4.3

Финальный установщик собран и проверен. Сейчас установлена версия 1.4.2. Обновление уже поручено пользователем и ожидает штатного выхода из Relay через меню в трее. Исследовательский MCP активирован отдельно.

## Изменения

- Enter и Space выполняют действие кнопки один раз. Отмена, переключатели и дочерние меню в проверенных диалогах сохраняют своё действие.
- Вложенные окна и меню возвращают фокус своему владельцу; Escape закрывает нужное окно. Проверено меню выбора языка.
- Текст сообщений, цитат и времени поверх медиа проверен в 11 темах. Исправлены состояния disabled/readOnly и отображение прогресса ползунка.
- Запись медиа в OPFS продолжает короткие операции до сохранения полного буфера. Ошибки диска и слишком больших ответов передаются как ошибки.
- X использует наблюдаемый original media source. Instagram выбирает валидный наблюдаемый источник с максимальной шириной. Выбранные permalink aliases и курсоры проверяются строго.

## Проверки

Прошли 322 теста Vitest в 26 файлах; отдельный набор исследовательского MCP — 151 тест; native-набор — 36 тестов и 4 проверки текущей версии. Наборы пересекаются, их результаты не суммируются.

UI: 31 сценарий пользовательских диалогов; основной набор — 63 PASS и 1 gate; 125 переходов — 109 body PASS и 16 gates. Проверены 11 тем и 66 образцов контраста, 7 контрактов клавиатуры и 3 сценария нагрузки. Замеры выполнены в headless-среде на этом компьютере.

Полные production/test проверки TypeScript проходят. Общий ESLint проверил 1862 файла: 0 ошибок, 1 сохранённое предупреждение в DocumentReader. Поток экранирования HTML изучен; предупреждение не подавлено.

Зафиксированы и проверены по SHA-256 все 3307 входов сборки и 40 файлов runtime. EXE извлечён из установщика. Все его байты совпадают с собранным приложением после точной штатной замены трёх байтов маркера Tauri UNK → NSS; эта проверка сохранена в payload receipt. Тестовая копия с тем же EXE и runtime прошла установку, запуск и удаление. У неё отдельные product/registry/identifier, отключены регистрация tg и обновление общего WebView. Рабочий Relay 1.4.2 и его процесс сохранились.

## Оставшиеся проверки

После установки 1.4.3 нужны живые проверки продолжения X, выбранной ссылки Instagram reel и оригинальных файлов. В точном перечне 138 диалогов тела 131 пока проверены только по исходникам. Частные беседы и отправка файлов в живой чат требуют выбранной пользователем цели. Локальные тесты не устанавливают скорость CDN или снимают серверные ограничения платформ.
