# Оболочка B: проверенный пакет

Rail занимает 4.5rem, системный заголовок — 2.5rem. Иконки сервисов выровнены по одной сетке; подписи на Inter размером 0.6875rem входят в кнопку целиком и допускают перенос. Выбранный сервис имеет контрастную поверхность и краевой маркер. Загрузка обозначается небольшим spinner, ошибка или требуемый вход — нейтральным маркером; состояние также присутствует в доступном имени кнопки. Кнопки и маркер изменяют цвет или прозрачность за 140мс; reduced motion отключает переходы и вращение.

Заголовок использует тот же фон темы, что и rail. Только короткий бренд Relay использует Unbounded. Кнопки окна, социальная навигация, вход X, результат обычной операции и Ctrl+J сохраняют свои действия. На узком рабочем пространстве бренд уступает место этим действиям. Размеры native-панелей здесь не анимируются.

`source.patch` сравнивает ровно шесть порученных файлов с рабочими байтами 1.5.0 перед этой подзадачей. Точные SHA-256 находятся в `source-hashes.json`; это не сравнение с Git HEAD. Журнал и транспорт медиа не входят в данный patch.

Текстовые области caption объявлены самостоятельными drag regions. Регрессия исполняет поставляемый с Relay vendored Tauri drag.js со stub IPC: оба текста запрашивают start_dragging, double click запрашивает toggle maximize; action buttons не вызывают drag. Исходный отказ и успешный тест сохранены раздельно.

Матрица включает 640×448, 800×560, FullHD, увеличение корневого текста до 200%, RTL, длинные тестовые подписи и reduced motion. В каждом случае проверены доступность кнопок заголовка, границы подписей, управление фокусом стрелками и сохранение сервиса после открывания/закрывания операций. Dark/Light integration отдельно проверяет чёрный или светлый общий фон, Unbounded бренда и Inter действий по computed styles.

Всё выполняется на настоящих компонентах App с существующим MockClient и native mocks. Внешние запросы заблокированы. Настоящие аккаунты, физическое DPI/GPU и системное окно Tauri не проверялись. Снимки содержат тестовую переписку; отсутствующий remote image и строка LastSeen.AtDate относятся к fixture. Данный пакет передаётся в общий frontend-цикл для окончательной приёмки и сборки.

## Повторение UI-проверки

Из корня проекта задайте `RELAY_SHELL_AUDIT_OUTPUT` собственным work-каталогом активной задачи Agent Brain. Скрипт хранит Vite cache, JSON и снимки только там. Использует установленный Edge; другой Chromium можно указать в `RELAY_UI_AUDIT_BROWSER`, свободный порт — в `RELAY_SHELL_AUDIT_PORT`.

```powershell
$env:RELAY_SHELL_AUDIT_OUTPUT = '<work текущей задачи>/shell-check'
$env:RELAY_SHELL_AUDIT_FONT_GATE = '1'
node docs/frontend-cycle-2026-10-06/shell/verify-shell-browser.mjs
```

`RELAY_SHELL_AUDIT_FILTER` принимает regex для адресного повторения, например `^(dark-full-telegram|light-800-telegram)$`. `verification.json` связывает проверки с логами и отдельными `geometry`/`integration`/`counts` снимками. Общий review board цикла принадлежит основному агенту.
