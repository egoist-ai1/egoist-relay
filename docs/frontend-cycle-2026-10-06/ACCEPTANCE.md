# Локальная приёмка Relay 1.6.0

Кандидат сохраняет Tauri/Teact/GramJS, профили сервисов и контракт медиа 1.5.0. Установщик подготовлен локально; агент не устанавливает его в ваш профиль и не отправляет сообщения. Фактические SHA-256, размер и подпись: [manifest.json](../../release/1.6.0/manifest.json).

## Запуск

1. Закройте работающий Relay обычным способом, чтобы закончились подтверждённые операции.
2. Откройте [Egoist Relay_1.6.0_x64-setup.exe](../../release/1.6.0/Egoist%20Relay_1.6.0_x64-setup.exe) двойным щелчком. Это локальный Windows x64-кандидат, без публичной подписи.
3. Запустите **Egoist Relay** из меню «Пуск». Сохранённые сервисы и выбранная тема должны восстановиться. Для единого чёрного оформления выберите **Настройки → General/Общие → Egoist Black**. Существующий валидный вариант темы намеренно сохраняется при обновлении.
4. Версия должна быть 1.6.0. Дополнительная регистрация Relay, подписка и облачный профиль не требуются.

Сборка из исходников: действующие команды `npm run build:desktop` и `npm run tauri:build`; Node24.11+ или 26, npm11/12, Windows Rust/MSVC согласно README. Агентские проверки использовали установленный bundled Node24.19 и runtime-кеши; точные команды и исключение повторного beforeBuildCommand находятся в [verification.json](verification.json).

## Интерфейс и восстановление

- Откройте Telegram, X и Instagram; переключайтесь мышью и клавиатурой. Контекст сервиса должен оставаться. Откройте панель кнопкой в оконной строке и Ctrl+J при фокусе в каждом сервисе.
- В 800×560 панель занимает рабочую область; вFullHD —24rem справа, если сервису остаётся 40rem. Закройте панель и проверьте возврат в прежний сервис и его поле ввода. Сузьте окно, пока фокус в переписке: фокус должен перейти в панель.
- Проверьте свою сохранённую светлую/тёмную тему после перезапуска. Оболочка, выбранный чат, основная кнопка, настройки и «Избранное» должны быть читаемы. Переключение темы сохраняет установленный размер текста.
- Проверьте текст 200%, длинный русский текст, масштаб Windows125/150/200%, доступ сTab/Shift+Tab/Enter/Space/Escape. Reduced motion должен убирать движение затронутых поверхностей. Браузерные 640×448 были проверкой устойчивости; native минимум —800×560.

## Медиа — только ваше «Избранное»

Используйте своё фото 3000×2000 и короткий ролик 1080p с доступным источником; каждый файл до 64 МиБ, набор до 128 МиБ и 10 элементов. Для сравнения SHA нужны именно полученные Relay байты: платформа могла обработать оригинал до Relay.

1. Сохраните оба файла локально. Закройте панель, продолжите чтение, подождите больше 6 секунд. Найдите файлы через «История → Открыть файл / Показать в папке».
2. Перезапустите Relay. История и пути должны восстановиться; открытие действительно должно открывать целый файл.
3. В новом диалоге проверьте старт **Ссылка**, затем отдельно **Медиа** и **Файл**. Адресат во всех случаях — только ваше **Избранное**. Закрытие подтверждённого диалога/панели не отменяет отправку.
4. Скачайте документ из «Избранного», отправленный в режиме «Файл», и сравните SHA-256 с локально сохранённой полученной версией:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '<локально сохранённый файл>'
Get-FileHash -Algorithm SHA256 -LiteralPath '<документ из Избранного>'
```

5. На следующей загрузке отключите сеть, отмените операцию, восстановите связь и выполните ручной повтор. Проверьте, что закрытие панели не останавливает другую подтверждённую работу.
6. Если отправка получила **«Исход неизвестен»**, сначала проверьте «Избранное». Автоматического повтора быть не должно; подтверждённые сообщения не отзываются. Не создавайте неопределённый исход специально на ценном наборе.
7. Удалите один тестовый локальный файл вручную и проверьте понятное объяснение недоступности. «Очистить историю» должно удалить записи, сохранив остальные файлы.
8. Заблокируйте Telegram: журнал должен скрыться, следующая отправка не должна начинаться. Смена аккаунта блокирует повтор старой пересылки; этот сценарий нужен только при наличии вашего второго аккаунта.

Запишите версию Windows/WebView2, масштаб, размер окна, выбранную тему, результат и шаг отказа. Личные переписки, cookies и токены передавать не требуется. Для обратной связи используйте [review-result.html](review-result.html): комментарий по объекту или общий комментарий, затем экспортJSON и передача в этот чат.

## Граница подтверждения

До выполнения вами этих действий реальная отправка, качество медиа, работа с вашим профилем, COM-фокус, native GPU/DPI и Narrator остаются непроверенными. Второе Windows-устройство и участник нужны для межконфигурационной приёмки. Публичная публикация требует отдельного решения о подписи и полноте corresponding source.
