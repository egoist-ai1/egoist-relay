# Egoist Relay — завершённый локальный фронтенд-цикл 1.6.0

Реализована выбранная композиция B с глубоким чёрным и нейтральными серыми в оболочке и собственных компонентах Telegram. Сохранены все 11 существующих вариантов, профили сервисов и медиа 1.5.0. Состояние: локальный кандидат готов; ручная приёмка живых медиа и установленного native-приложения отдельно.
