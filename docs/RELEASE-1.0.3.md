# Egoist Relay 1.0.3 — прямой вход X

X остаётся внутри Relay. Вариант входа выбран пользователем: почта/имя пользователя и пароль X, без переноса сессии из внешнего браузера.

## Изменения

- В верхней панели X добавлена кнопка «Вход по логину X», открывающая актуальную официальную страницу `https://x.com/` с полем почты/имени пользователя в существующем WebView, без дополнительного модального маршрута.
- Попытка открыть Google OAuth показывает понятное объяснение и кнопку перехода к прямому входу. Неподдерживаемое Google-окно не создаётся; если провайдер начинает с `about:blank`, такой popup закрывается при переходе к Google.
- Подсказка сохраняется при переключении Telegram → X. Фоновые события загрузки не скрывают её.
- Для входа предлагается пароль X. Если аккаунт создан через Google и отдельного пароля нет, пользователь может воспользоваться «Забыли пароль?» на официальной странице X.
- Cookies, localStorage и каталог профиля не очищаются и не меняются. При запуске уже авторизованный X продолжает открываться обычным способом; автоматического принудительного перехода к login нет.

## Проверки

TypeScript, целевые ESLint/Stylelint и Rust check прошли. Глобальные ранее существовавшие lint-замечания проекта не объявляются исправленными.

Финальный release EXE проверен в отдельном WebView2-профиле:

- Google → подсказка прямого входа; число Google popup — 0.
- Подсказка сохраняется после переключения Telegram/X.
- Переход возвращает рабочий X WebView на `/`; поле принимает синтетический идентификатор, «Продолжить» становится доступным.
- Постоянная HttpOnly-cookie и localStorage сохраняются после полного перезапуска.
- Размер клиентской области остаётся 1652×1160, верхняя панель — 40 px.
- Обычное закрытие завершает собственные процессы и освобождает тестовые порты.

Production frontend и Rust release собраны. NSIS упакован отдельной командой `tauri bundle --bundles nsis` после закрытия тестового EXE; команда завершилась успешно.
