# Egoist Social 1.9.0

13 октября 2026. Новое имя и знак, тихая оболочка, своя изолированная сеть, надёжность WebView2 и журнала медиа. Цикл и решения владельца — [docs/product-cycle-2026-10-13](product-cycle-2026-10-13/), продукт — [PRODUCT.md](PRODUCT.md), интерфейс — [DESIGN.md](DESIGN.md).

## Что изменилось

### Имя и вид

- **Egoist Social** вместо Sennit; знак «Реплика-E» ([BRAND.md](brand/BRAND.md), [NAMING.md](brand/NAMING.md)). Иконки приложения, установщика, трея и favicon собираются из одного источника (`docs/brand/build_assets.py`). Технические идентификаторы (`com.egoist.relay`, Control API, MAGIC установщика) не менялись, поэтому обновление идёт поверх и профили сохраняются.
- **Оболочка «Тихая рамка»:** rail только из иконок 40×40, состояние — точкой (загрузка, ошибка или вход, сон), индекс `01/03` в заголовке убран.
- **Скрытие сервисов:** в «Настройки → Общие» можно скрыть X и/или Instagram. Скрытый сервис уходит из rail, не прогревается и не создаёт сетевой нагрузки. Telegram виден всегда.

### Своя сеть

- Все окна (Telegram, X, Instagram, mini-apps, исследовательские окна), загрузка медиа и мост Telegram идут через собственный Xray на случайных loopback-портах 20000–60000 (вне диапазонов Egoist Lagom). Контракт — [NETWORK-TUNNEL.md](product-cycle-2026-10-13/NETWORK-TUNNEL.md).
- **Лестница маршрутов:** VPN + свой DoH → напрямую + свой DoH → автоматический возврат в туннель. Системный DNS и прокси Windows не используются никогда. Если приватный DoH недоступен, временно работает публичный (1.1.1.1, 8.8.8.8), это видно в настройках.
- **Система не трогается:** DNS, прокси Windows, маршруты, TUN, службы и драйверы не меняются; права администратора не нужны. Работает рядом с Lagom, Zapret и другими VPN.
- **Ключи:** ключ VPN или подписка и ссылка DoH вшиты в личный установщик, после установки хранятся под DPAPI текущего пользователя. Конфиг Xray с ключом передаётся процессу через stdin и на диск не пишется. Во фронтенд, журнал и командные строки значения не попадают.
- **«Настройки → Сеть»:** состояние, узел, DNS, маршрут каждого сервиса; замена ключа, подписки, DoH и MTProxy с проверкой на втором Xray до применения и откатом при неудаче; «Обновить подписку» (и автоматически каждые 12 ч); «Вернуть встроенные».
- **Telegram:** стандартный wss Telegram Web A через туннель; MTProxy — необязательная ступень через тот же туннель. Чтение MTProxy-файлов Egoist Lagom убрано. FakeTLS-прокси (`ee…`) отклоняются с понятной ошибкой.
- **Медиа:** только через туннель (`socks5h`), без прямого запасного пути. Модуль системного прокси (`system_proxy.rs`, WinHTTP/PAC) удалён.

### Надёжность

- Скрытые X и Instagram уходят в сон (`MemoryUsageTargetLevel=Low`, затем `TrySuspend`) и просыпаются при показе; в rail — отметка сна.
- Операции с окнами выполняются на главном потоке с типизированными ошибками: таймаут повторяется один раз и не пересоздаёт здоровый WebView; пересоздание — только для мёртвого контроллера, не чаще 3 раз за 5 мин.
- Падение процесса WebView2: выход рендерера → перезагрузка; зависание → ожидание 5 с, затем перезагрузка; полное пересоздание — только при выходе браузера. Неудачная загрузка повторяется через 3 с.
- Журнал операций медиа пишет стадии сразу (ошибка записи не теряется молча), прогресс — с задержкой, при выходе — сброс на диск.
- Исследовательские окна не открываются ради проверки статуса и закрываются после 30 мин простоя.
- Мост Telegram переживает обрыв сырого сокета и пишет причину выхода; GramJS подхватывает новый адрес моста при смене MTProxy без перезапуска.
- Обновления отключены (updater OFF), версии ставятся установщиком.

## Не проверено

Проверки выше синтетические; живая приёмка — на ПК владельца после установки:

- Реальные узлы подписки (reality, xhttp) и готовность Xray за 1,5 с на старте; загрузка настоящей подписки.
- Переход в «Только DNS» при нерабочем ключе (~15 с) и возврат в туннель (≤ 2 мин).
- Звонки Telegram (UDP мимо прокси запрещён — качество может быть ниже).
- Сон и пробуждение, смена сети; работа при включённом TUN Lagom.
- В Resource Monitor внешние соединения только у `xray.exe`.
- Установка на чистой машине из одного exe; `ERROR_INVALID_STATE` WebView2 на профилях, обновлённых с 1.8.x.

## Известные ограничения

- MTProxy FakeTLS (`ee`) не поддерживается.
- После сна восстановление идёт штатными пробами раз в 5 с (не внеочередной серией), переход между ступенями — не раньше 60 с.
- Очистить только один свой параметр (например, MTProxy) нельзя: «Вернуть встроенные» сбрасывает все.
- Ключ VPN лежит в хвосте личного установщика открытым JSON: установщик нельзя передавать другим.
- Фича `devtools` в Tauri оставлена для диагностики владельцем.
