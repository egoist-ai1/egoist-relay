# Проверка достоверности экспортов

Исправление проверено в исходниках и в свежем экспорте через обновлённый daemon. Relay остаётся установленной версией 1.4.2.

В двух выбранных публичных выгрузках Instagram Markdown содержал только заголовки (84 байта на три записи). JSONL при этом содержал description и observedText. Новый форматтер показывает эти поля отдельно, добавляет исходные ссылки, номер строки JSONL и локальные принятые файлы с SHA-256. Описание страницы не выдаётся за восстановленную подпись поста.

Проверено: восемь тестов фактического writer (до исправления 0/8, после 8/8); сорок существующих тестов writer/broker; повторное форматирование двух точных публичных JSONL с неизменным SHA; отображение HTML и Markdown в изолированном Chromium. Ширины 320/480/1280/1920 px не дают горизонтального переполнения, вредоносно выглядящий текст остаётся буквальным, сетевых запросов — ноль.

JSONL, очередь, аккаунтная привязка и транспорт не менялись. Частичный успех маркируется; полнота источника не устанавливается. После ошибки по-прежнему сохраняются JSONL и partial-manifest без новых человеческих производных — этот участок не входил в исправление.

Доказательства и четыре нейтральных объекта для общего companion review board находятся в [export-fidelity-audit.json](export-fidelity-audit.json). Синтетический пример: [export-html-fullhd.png](export-html-fullhd.png).

Свежая проверка Instagram: задание 036b4b92-9226-4cf1-bc5a-5101757adb05, partial/3 записи. JSONL — 8351 байт, Markdown — 8175 байт, HTML — 10604 байт. Буквальное содержимое обоих производных документов дополнительно проверено в изолированном браузере без сетевых запросов. Подробности: [export-live-instagram.json](export-live-instagram.json).
