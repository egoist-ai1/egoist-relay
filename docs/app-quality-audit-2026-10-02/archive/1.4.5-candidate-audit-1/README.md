# Egoist Relay: аудит кандидата 1.4.5

Relay 1.4.5 установлен и запущен по свежему прямому разрешению пользователя. Exact EXE и 40 runtime файлов сверены. Существующие аккаунты Telegram, X и Instagram подтвердили ready; новый MCP daemon использует текущий source hash. Новых research jobs и реальных сообщений нет. Native Reels visual check остаётся ожидающим.

Прежний агрегат `1.4.4-candidate-audit-3` из 74 объектов сохранён побайтно в [версионном архиве](archive/1.4.4-candidate-audit-3/archive-manifest.json). Пакет 1.4.4 остаётся историческим и не установлен. Платёжный draft v2 исключён и ожидает отдельного явного решения.

Все 108 объектов новой доски имеют нейтральный выбор. Пользовательские ответы не выдуманы и не перенесены. Подтверждение принимает действие, описанное в конкретном объекте; кнопка «Применить» передаёт обратную связь в задачу или сохраняет JSON для передачи.

## Установленная версия и сохранение настроек

[Installation](../release-1.4.5/installation.json) связывает рабочий EXE с проверенным пакетом; [свежее разрешение](../release-1.4.5/installation-approval.json) относится именно к 1.4.5. [Live receipt](../release-1.4.5/live-verification.json) подтверждает три existing-account bridges ready и текущий MCP source hash; queued/running — 0, новых research jobs и реальных сообщений — 0. Это readiness и identity proof. Native Reels visual check ожидает ответ пользователя.

Сравнение с историческим baseline 09:09: совпали 6 из 7 file hashes и 2 из 3 прежних PID. Изменение SystemDoH config в 12:04 предшествовало установке в 12:39; текущая служба DoH работает. Это не непосредственный before/after установки. Root не выполнял команды изменения сети, служб или приоритета и не восстанавливал пользовательский config.

## Условия, которые ещё не проверены

138 файлов категории Modal/Dialog — это исходный каталог, а не 138 полных live сценариев. 125 route attempts также не означают полные submit/account сценарии. Частные беседы требуют точно выбранных пользователем целей; live upload — разрешённого получателя и поддерживаемого фонового действия либо ручного действия в приложении.

Native Windows DPI, text zoom, физический GPU, native Tab flows, геометрия каждого кадра закрытия, скорость CDN, server acceptance, реальное авторство/коллаборация Instagram и точность ASR на реальной речи сохраняют отдельные gates. В этой задаче обновления отчёта аккаунты, службы, DNS/DoH/Lagom, системные настройки и live операции не читались и не менялись.

[Матрица требований](requirements.json) · [Сводка проверок](validation-summary.json) · [Review board](review.html) · [Точный снимок](Реестр.json).

Подтверждение board принимает конкретный показанный результат без автоматической установки, платежа или отправки сообщения. Старый снимок и прежние receipts остаются доказательством только той версии и области, к которым относятся.

Автоматическая проверка отклонила удаление барьера свежего согласия из production installation helper: подготовка обновления не разрешает обходить явный защитный контроль. Production helper сохранил approval gate. Барьер разрешён свежим прямым ответом пользователя, без обхода контроля; точный первоначальный статус и причина записаны в [release-ready.json](../release-1.4.5/release-ready.json).
