# Egoist Relay: аудит и доработка

Рабочий Relay 1.4.2 сохранён. Кандидат 1.4.4 содержит четыре адресных исправления диалогов и native bridge; его точный статус указан в release-ready. Исправленный исследовательский daemon уже активирован: после 17 секунд idle сохранил одну публичную запись X через аккаунт пользователя. Для новых исходников прошли 322 Vitest, 178 MCP, 40 native и все четыре контекста TypeScript; ESLint — 0 ошибок и 1 прежнее предупреждение. Платёжный патч v2 не включён и ждёт явного согласия. Таблица ниже сохраняет предыдущий полный gate-снимок 1.4.3; новые receipts и ограничения приведены в объектах обратной связи.
