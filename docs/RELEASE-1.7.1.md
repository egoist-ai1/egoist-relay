## Что нового

- **Название и знак.** Продукт называется **Sennit** (подпись «by Egoist»): знак — буква S из трёх полос, монохром Lagom. Исходники — `docs/brand/`, обоснование — `docs/brand/NAMING.md`. Внутреннее имя (`productName`, exe, папка установки, AppData, профили, named pipe) оставлено «Egoist Relay», чтобы обновление не сломало профили; ярлыки пока называются по-старому.
- **Модалка «Выберите получателей».** Список больше не схлопывается (56 → 97–209 px на 100 %). Исправлены наложения: полоса перетаскивания перехватывала клики по заголовку чата, узкая колонка выходила за окно при 200 %, строки пикеров накладывались при крупном тексте. 624 состояния при 100 % без находок. [UI-POLISH](lagom-redesign-2026-10-07/UI-POLISH.md)
- **Удалённые сообщения.** На месте удалённого — строка «Сообщение удалено», по клику раскрывается само сообщение. Хранение локально (IndexedDB), по умолчанию включено: 90 дней / 200 МБ, настройка и «Очистить» в Конфиденциальности; секретные чаты и сообщения с таймером не сохраняются. Сохраняется только то, что клиент уже получил. Риск по условиям API Telegram — в [DELETED-MESSAGES](lagom-redesign-2026-10-07/DELETED-MESSAGES.md).
- **Время входа.** В активных сеансах и веб-сеансах — точное время входа (`date_created`) и отдельно последняя активность. Время входа других людей Telegram не раскрывает.
- **Отправка файлов.** Клиентских потолков не было: лимит берётся с сервера (≈2 ГБ, Premium ≈4 ГБ). Добавлены возобновление после обрыва, повторы временных ошибок, понятная ошибка превышения. Скорость сети не менялась и на живом аккаунте не измерена. [UPLOAD-SPEED](lagom-redesign-2026-10-07/UPLOAD-SPEED.md)
- **Instagram → Telegram.** Шаринг убран (кнопка, перехват, Rust-ветки). Шаринг X сохранён. [INSTAGRAM-SHARE-REMOVAL](lagom-redesign-2026-10-07/INSTAGRAM-SHARE-REMOVAL.md)
- **Social MCP.** Закрыт доступ к личным диалогам Telegram через `social_plan`; исправлены даты и тема для X/Instagram, нормализация медиа, FTS для русского (ё/е), диагностика старта; нестабильные тесты планировщика. 273 из 273. [MCP-AUDIT](lagom-redesign-2026-10-07/MCP-AUDIT.md)
