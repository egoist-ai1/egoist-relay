# Egoist Social 1.9.7

## Что изменилось

- Для собственного Telegram helper сохраняется маршрут DC→IP только для DC4: `149.154.167.220`. DC2 использует fallback через Cloudflare согласно upstream [CfProxy.md](https://github.com/Flowseal/tg-ws-proxy/blob/v1.7.0/docs/CfProxy.md), который рекомендует этот способ при проблемах с загрузкой медиа у пользователей без Premium.
- Таймаут первого ответа local bridge увеличен с 12 до 45 секунд. Таймаут локальной plain-auth GramJS увеличен с 15 до 45 секунд. Таймауты browser и test сохраняют прежние значения.
- Экспортируемый sender больше не принимает наличие crypto key за успешный `ImportAuthorization`: после неудачного импорта выставляется retry flag и авторизация повторяется.

## Диагностика 1.9.6

После 1.9.6 владелец подтвердил, что фотографии из аккаунта не загрузились: 0 успешных. В живом CDP тесте получен `MTPROTO_CLUSTER_INVALID` при открытых сокетах DC2 media и нулевом буфере отправки. Этот код ошибки сам по себе не означает, что интерфейс или интернет полностью недоступны. Ранее успешный ReqPQ проверял только транспортный обмен и не подтверждал успешность file RPC или загрузку фото.
