# Sennit — знак и правила использования

Режим Egoist DS: Lagom (монохром, строгая геометрия, без акцента). Значения цветов и шрифтов — из `Egoist Design System/tokens/tokens.json`. Название и обоснование — [NAMING.md](NAMING.md).

## Идея знака

Sennit — шнур из прядей. Знак: буква S, собранная из трёх горизонтальных полос, соединённых двумя полукруглыми изгибами. На изгибах просветы 3,5 из 64 («нить проходит под нитью»): три потока в одном плетении. Ничто не заимствует форму бумажного самолётика, птицы, камеры или их глифов.

## Файлы

| Файл | Назначение |
|---|---|
| `mark.svg` | Знак для тёмного фона (цвет graphite-100) |
| `mark-light.svg` | Знак для светлого фона (graphite-900) |
| `wordmark.svg`, `wordmark-light.svg` | Слово Sennit, контуры Unbounded 500, трекинг −0,02 em |
| `lockup.svg`, `lockup-light.svg` | Знак + слово: основной вариант на шапках, README, заставках |
| `app-icon.svg`, `app-icon-light.svg` | Плитка 64 с радиусом 14 для иконки приложения, favicon, магазинов |
| `preview.png` | Контрольный лист: 16/24/32/48/256, тёмная и светлая тема |
| `build_logo.py` | Генератор SVG (нужен fonttools). Знак — геометрия, слово — контуры шрифта |

Имя `-light` значит «для светлой темы», а не «светлый знак».

## Цвета

| Роль | Токен | Значение |
|---|---|---|
| Знак на тёмном | graphite-100 | `#EDEBE6` |
| Знак на светлом | graphite-900 | `#0E0E0F` |
| Плитка тёмная | graphite-850 | `#141416` |
| Плитка светлая | graphite-50 | `#F5F5F2` |
| Подпись «by Egoist» | graphite-500 / 400 | `#646460` / `#8C8A85` |

Контраст (WCAG): `#EDEBE6` на `#0E0E0F` 16,2:1; `#0E0E0F` на `#F5F5F2` 17,7:1; знак на плитке `#141416` 15,4:1. Акцент (лайм) в знаке не используется.

## Шрифты

Слово Sennit — Unbounded 500 (OFL, кириллица есть, но слово латинское и вынесено в контуры). Подпись «by Egoist» — Onest 500 строчными либо JetBrains Mono капсом 0,08 em как метка сетки. Файлы лицензий — `public/fonts/*-OFL.txt`.

## Охранное поле и размеры

- Охранное поле: ширина штриха знака (9/64 высоты плитки) × 2 со всех сторон. Для lockup — высота прописной буквы слова.
- Минимальный размер знака: 16 px (проверено на листе), для плитки с радиусом — 16 px. Lockup не меньше 96 px по ширине; в меньших местах используется один знак.
- Для 16–24 px знак всегда на плитке или на контрастном поле; просветы при 16 px исчезают субпиксельно, S остаётся читаемым.

## Запреты

- Не менять пропорции, штрих, радиусы, просветы, не добавлять обводку, тень, свечение, градиент, акцентный цвет.
- Не вращать, не наклонять, не обрамлять другой формой; не ставить рядом с знаками Telegram, X, Instagram и не использовать их формы.
- Не ставить знак на фон с контрастом ниже 4,5:1 и на изображения без плитки.
- Не набирать слово другим шрифтом и не писать капсом; не заменять S на другие буквы.
- Метки фирменной сетки (кресты, индекс) живут на полях кадра презентации и промо, но не внутри знака и не в мастере установки.

## Голос

Имя пишется Sennit (без «The», без «App»). Подпись — «by Egoist». Описание — «локальный хаб ваших мессенджеров и соцсетей». Не обещать связи с сервисами: «неофициальный», названия сервисов — только как описание того, с чем он работает.

## Где применено

Заголовок окна и Titlebar (`SennitMark`), иконки приложения (`tauri/icons`), favicon и PWA-иконки (`public`), страницы и шапка NSIS (`nsis-header.bmp`, `nsis-sidebar.bmp`), README, строки интерфейса. Подробности и что оставлено прежним — `docs/lagom-redesign-2026-10-07/BRAND.md`.
