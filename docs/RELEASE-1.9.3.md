# Egoist Social 1.9.3

13 октября 2026. Правка после установки 1.9.2; остальное — как в [1.9.2](RELEASE-1.9.2.md), [1.9.1](RELEASE-1.9.1.md) и [1.9.0](RELEASE-1.9.0.md).

## Что изменилось

- **Закреплённый на панели задач значок больше не пустеет после обновления.** Установщик Egoist Social запускал встроенный NSIS только с `/S`. Шаблон Tauri в таком режиме считает обновление переустановкой: вызывает старый деинсталлятор как полное удаление, тот открепляет приложение от панели задач и удаляет ярлыки. Ярлыки на рабочем столе и в «Пуске» создаются заново, а файл закрепления (`User Pinned\TaskBar\Egoist Relay.lnk`) нет. Запись о закреплении остаётся и показывает пустой лист. Теперь обновление поверх установленной версии идёт с `/S /UPDATE`, как у штатного обновлятора Tauri: старый деинсталлятор не запускается, ярлыки, закрепление и автозапуск не трогаются. Первая установка по-прежнему идёт с `/S`: ярлыки создаются, WebView2 ставится при необходимости.
- Правка из 1.9.2 (`SHChangeNotify` в конце установки) осталась. Сама по себе она не помогала: перечитывать значок было не из чего.

## Проверки

- `cargo test` установщика — 43/43, включая новый тест аргументов NSIS (обновление — `/S /UPDATE`, первая установка — `/S`, мастер — без аргументов).
- `npm run release:preflight` — пройден.
- На ПК владельца закрепление восстановлено вручную: ярлык из «Пуска» скопирован в `User Pinned\TaskBar`, `SHGetFileInfo` отдаёт значок для обоих ярлыков.
- Тихая установка 1.9.3 поверх 1.9.2 (`--silent --launch`): в журнале `NSIS запущен …, аргументы: /S /UPDATE`, файл закрепления не тронут (время изменения прежнее), значки на месте, приложение запустилось. Установщик `release/1.9.3/Egoist-Social-Setup-1.9.3.exe` (579677879 байт, SHA-256 `8a3a10e3e3dcd28c525756bc96522a1581964c631294061af96e2e2e5e877acf`).

## Не проверено

- Вид панели задач глазами: проверено по файлам и `SHGetFileInfo`, не по скриншоту.
- Если ярлык на рабочем столе удалён вручную, обновление его не вернёт (так же ведёт себя штатное обновление Tauri). Вернуть можно переустановкой после удаления.
