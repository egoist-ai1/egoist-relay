# Береста — продукт

Береста (с 25.10.2026; до этого Egoist Social, внутреннее имя Egoist Relay, в 1.8 — Sennit) — личный Windows-хаб владельца для чтения Telegram, X и Instagram в одном окне, с локальным сохранением медиа и явной пересылкой между сервисами. Один пользователь, один компьютер, без облака и собственных аккаунтов.

## Для кого и зачем

| Кто | Задача | Что важно |
|---|---|---|
| Владелец, ежедневно | Держать Telegram открытым весь день, заглядывать в X и Instagram | Не тормозит после многих часов работы, не теряет вход, переключение мгновенное |
| Владелец, иногда | Сохранить видео или фото, переслать пост в Telegram | Видно, что происходит с загрузкой; ничего не теряется при сбое |
| Агенты владельца (Social MCP) | Читать ленты через его аккаунты | Только чтение, без отправки и публикации; не мешает работе в окне |

## Принципы

1. **Содержимое важнее рамки.** Оболочка тихая: rail из иконок, бренд один раз, монохром Lagom без акцента ([DESIGN.md](DESIGN.md)).
2. **Ресурсы по потребности.** Скрытый сервис засыпает (WebView2 `MemoryUsageTargetLevel=Low`, затем `TrySuspend`), просыпается за секунду. Telegram не усыпляется, пока окно на экране.
3. **Сбой — это состояние, а не тупик.** Каждый сервис показывает загрузку, ошибку с причиной и действием, сон. Оболочка сама пробует восстановиться один раз и пишет причину в журнал.
4. **Данные пользователя неприкосновенны.** Профили, логины и журнал операций переживают обновление и аварию; миграции профилей — только решением владельца.
5. **Своя сеть, чужую не трогаем** (решение владельца 13.10.2026, с 1.9.0). Приложение поднимает собственный туннель только для своих процессов: Xray на loopback, лестница «VPN + приватный DoH → напрямую с приватным DoH», автоматический возврат. Ключ и DoH вшиты в установщик и заменяются в настройках. DNS, маршруты, системный прокси, TUN и Zapret Windows не меняются, с Lagom и другими VPN не конфликтует. Скрытый в настройках сервис не загружается.

## Критерии качества

| Область | Критерий | Как проверяем |
|---|---|---|
| Отклик | Переключение сервиса и открытие панели ≤ 100 мс до первой реакции интерфейса | `scripts/relay-ui-audit.mjs`, профиль CDP |
| Ресурсы | Скрытые X/IG засыпают; после 8 ч память не растёт без предела | замер процессов WebView2 по окружениям ([исходная точка](product-cycle-2026-10-13/BASELINE.md)) |
| Надёжность | Свернуть/развернуть не переводит сервис в ошибку; падение процесса WebView2 или моста Telegram восстанавливается без перезапуска | `cargo test`, ручные сценарии из [AUDIT-BACKEND.md](product-cycle-2026-10-13/AUDIT-BACKEND.md) и [AUDIT-TRANSPORT.md](product-cycle-2026-10-13/AUDIT-TRANSPORT.md) |
| Данные | Журнал операций и профили не теряются при аварии и обновлении | тесты `media_operations`, обновление поверх установленной версии |
| Доступность | WCAG 2.2 AA: контраст, фокус, клавиатура, 200 % текста, reduced motion | `scripts/qa-lagom/*`, `relay-frontend-acceptance.mjs` |

## Вне рамок

Отправка и публикация от имени владельца агентами; синхронизация между устройствами; поддержка macOS; новые соцсети без решения владельца.
