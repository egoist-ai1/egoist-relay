# План исправлений после свежего аудита 1.3.0

Дата: 29 сентября 2026. Исходная сборка: 1.2.6. План записан до продуктовых изменений этого аудита. Подробные исходные воспроизведения находятся в `audit-1.3.0/{media,network,ui,release}.md`.

## Исходные проверки

- Frontend: 197/197 Vitest; Rust: 58/58. TypeScript и lint завершились без ошибок; CSS имеет 510 предупреждений исходного дерева.
- Сеть: 100/100 Node и 46/46 целевых Rust; media: 27/27 Node и 50/50 целевых frontend. Эти выборки пересекаются с общими наборами и не суммируются как независимые тесты.
- UI: 37 синтетических случаев actual components в Edge, 14 новых снимков. Большой документ создаёт 40004 DOM-узла; при тексте 200% заголовок выходит за доступную ширину.
- Нативная 1.2.6 в отдельном пустом профиле: reuse, reject-external и close-restore прошли, окно остаётся одним. Обычное завершение собственного процесса подтверждено. X/Instagram в исходном generic сетевом режиме не дали успешного WAN-соединения; локальная готовность прокси этого не доказывает.
- Production npm audit: 0 известных advisories; полный audit: 3 moderate записи одной dev-цепочки bundle-stats. Tauri2.11.5 затронут опубликованным high advisory GHSA-w28w-mhc8-qvjv.

## Завершение

Новые generic и personal installers должны пройти отдельную проверку payload и установки; личные DNS/tunnel данные допустимы только в personal артефакте. Финальный отчёт разделяет подтверждённые исправления, проверенные сценарии и оставшиеся условия выпуска.

Подпись издателя, второй чистый ПК, реальные аккаунты другого пользователя и 24–72 часа эксплуатации нельзя заменить unit tests. Без фактических подтверждений эти пункты не будут отмечены пройденными. Публикация и отправка сообщений в этом аудите не выполняются.
