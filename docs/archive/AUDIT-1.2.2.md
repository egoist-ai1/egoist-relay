# Аудит Egoist Relay 1.2.2

Продолжение принятой 1.2.1 по указанному Instagram Reels. Готовый установщик исправляет загрузку, размер сообщения и фактическое подключение автозапуска. Предыдущий полный аудит, исходные результаты и артефакты 1.2.1 сохранены отдельно.

## Найденные причины и изменения

- Instagram не передавал duration/is_live и кодеки. Фильтр yt-dlp исключал доступное видео, а раздельный шаблон метаданных формировал невалидный JSON с NA. Исправлены проекция JSON, обработка отсутствующей длительности только для Instagram и подбор формата. Фактический файл обязательно проходит ffprobe: положительная конечная длительность до 600 секунд, видеопоток, сопоставление с известной длительностью источника.
- Соотношение 9:16 применялось также к ошибке и загрузке: пустая карточка становилась огромной. Ожидание и загрузка теперь занимают 142 px; ошибки — около 169–187 px в проверенных вариантах. Ошибка сохраняется при прокрутке и смене сервиса, явный Retry запускает одну попытку.
- Глобальные !important в тёмной теме переопределяли ширину внешнего сообщения. Минимальная fixture не охватывала этот каскад; настоящий MCP-прогон обнаружил остававшуюся пустую колонку. Добавлено узкое правило только для встроенных плееров и проверки полного каскада с реальными классами Message. Неподходящая промежуточная сборка отмечена как историческая и не принята.
- Автозапуск ссылочного плеера использовал Telegram-селектор, который возвращает undefined без собственного video в webPage. Встроенный плеер теперь получает существующую настройку autoplayVideos отдельно. Защита сообщений, необходимость превью, автозагрузка, уменьшение движения и существующий селектор обычного Telegram-видео сохранены.

## Настоящее окно и существующий аккаунт

Использован выделенный window-bound MCP 1.0.5 с 20 инструментами и точной привязкой к собственному процессу окончательного EXE. Открыт локальный ряд чата с Reel Ddxw2KWMebQ; ссылка источника и Play до проверки автозапуска не нажимались. Плеер достиг playing, readyState 4, paused false: настоящий HTML5 video, iframe отсутствует. После возврата из соцсети автозапуск подтверждён повторно.

Визуально проверено согласование внешнего сообщения и видео: карточка 318 × 608 px, без прежней пустой колонки справа. Остановка дала idle 318 × 142 px без видео; каталог собственных job-файлов пуст. Личные переписки и скриншоты не сохранены в отчёт.

В X и Instagram ленты доступны, встроенные кнопки «Поделиться в Telegram» присутствуют, выбор получателя открывается, Send исходно отключён, Close возвращает исходную соцсеть. Получатели не выбирались, сообщения не отправлялись. X: page errors 0, один отменённый медиазапрос. Instagram: один other-error официального скрипта сайта, один индикатор загрузки, request failures 0. Соединения обеих соцсетей использовали TLS 1.3. Telegram bridge/proxy и DPI proxy были ready. Аккаунтные и системные сетевые настройки не менялись.

Короткая фоновая выборка: 1501,4 мс, 44 кадра, медиана 33,4 мс, P95 33,5 мс, long tasks 0. document.visibility сообщал visible, но нативное окно скрыто/перекрыто; это не доказательство видимой частоты кадров или плавности всех анимаций. Собственная сессия завершена штатно через точный MCP, helper закрыт.

## Границы результата

Это исправление конкретных отказов поверх предыдущего полного аудита. Отправка с подтверждением/автозакрытием и очисткой данных сохраняет синтетические результаты 1.2.1 при неизменённом коде; реальная отправка повторно не выполнялась. YouTube в новых UI-fixtures проверен доверенным mock-iframe, а не новым реальным воспроизведением. Fixtures используют production-классы, каскад и извлечённые выражения; полный аккаунтный Message монтируется и проверяется отдельно только настоящим MCP.

Загрузки других публикаций зависят от доступа и ограничений провайдера. Сохранены лимиты 600 секунд, 64 МиБ и таймауты. 720p — предпочтение по метаданным, без отдельной проверки фактической высоты. Literal private IP и посторонние hosts запрещены; отдельный DNS IP-pinning не добавлялся. Нет гарантии точности любой шумной голосовой записи, доступности закрытых публикаций, работы каждой функции стороннего сайта или совместимости с каждой комбинацией VPN/DNS. Чистая Windows без WebView2 и обновление поверх пользовательской установки в этом прогоне не выполнялись.
