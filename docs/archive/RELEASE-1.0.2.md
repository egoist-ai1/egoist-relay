# Egoist Relay 1.0.2

## Исправлено по скриншотам

- Аватар обычного сообщения отрисовывается один раз. Групповой sticky-аватар не создаётся там, где уже есть аватар строки. Убрано скрытие по подстроке имени CSS Module: оно не работало после production-хеширования.
- Контакты без фотографии показывают читаемые инициалы на тёмном фоне вместо белого круга с белыми буквами.
- В личном чате не повторяется имя собеседника над каждым блоком сообщений. Подписи в группах, цитатах и пересылках сохраняются.
- Стандартная реакция сразу показывает Unicode-эмодзи. Telegram thumbnail или полное изображение заменяет его только после загрузки; при ошибке остаётся видимый fallback. Кастомные и платные реакции сохраняют свои специализированные компоненты.
- На узких окнах фиксированная колонка Telegram ограничена рабочей областью справа от переключателя приложений.
- Нативная строка заголовка занимает отдельные 40 px, чтобы кнопки окна не пересекались с действиями чата.

## Размер окна

Размер по умолчанию — **1652 × 1160 логических пикселей**. Он измерен по клиентской области открытого приложения пользователя при DPI 96. Минимум — 800 × 560; если рабочая область монитора меньше заданного размера, стартовое окно уменьшается до доступного пространства.

## X и Google

Запросы `window.open` из X обрабатываются через `on_new_window`. Создаётся связанное окно `x-auth-*` с WebView2 environment/profile исходного окна. `window.opener` и возврат OAuth остаются доступны сайту. Окно принадлежит физическому главному окну, включая состояние, когда в нём несколько WebView.

Каталог X остаётся прежним `app_local_data_dir`; новая отдельная папка авторизации не создаётся. Cookies и localStorage не очищаются при переключении приложений, закрытии popup или обычном перезапуске. Удалённые окна не получают привилегий локального интерфейса Tauri.

## Проверка

Использованы реальные компоненты Teact и настоящие преобразователи данных worker, с синтетическим сценарием `relay-ui`. Личные переписки и профили пользователя не использовались.

- Production-сборка с хешированными CSS Modules: личный чат и канал при 1652×1160, 1000×760, 800×560.
- По одному аватару у обычного сообщения, ноль дублирующих групповых аватаров.
- Видимые эмодзи 20×20 px, в том числе девять реакций с переносом строк.
- Проверены ответы, метаданные сообщений, светлый текст на тёмных аватарах-заглушках и границы рабочей области.
- В изолированном native debug-профиле реальная кнопка Google открыла страницу `accounts.google.com`, `window.opener` был доступен, закрытие popup работало, команда Tauri из удалённого окна была отклонена.
- Постоянная тестовая cookie X пережила полный перезапуск native-процесса.
- TypeScript, целевые ESLint/Stylelint и Rust check прошли. Общий lint репозитория сохраняет ранее существовавшие замечания вне исправленной области.

## Границы

Google-логин проверен до страницы ввода аккаунта. Пароли, коды и аккаунты не вводились: завершённая авторизация и решения серверов Google/X не заявляются как проверенные. Проверка постоянной cookie подтверждает сохранение профиля, но не отменяет возможного истечения или отзыва настоящих сессий сервером.

Существующие параметры Telegram-форка и схема подключения сохранены. Новый API ID не регистрировался; серверные ограничения из отчёта 1.0.1 остаются применимыми.
