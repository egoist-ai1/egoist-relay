# Egoist Relay 1.2.3

[Windows x64 установщик](../release/1.2.3/EgoistRelay_1.2.3_x64-setup.exe), 594 514 142 байта.

Общие адаптивные карточки Telegram применяются к существующим и будущим сообщениям. Вертикальное видео сохраняет пропорции без пустой колонки, горизонтальное становится крупнее, альбом заполняет карточку. Дублирующее описание превью скрывается только при совпадении с заголовком. Подписи, пересланный заголовок и время сообщения остаются внутри согласованной композиции. Обычный текст, голосовые, стикеры, круглые видео и документы сохраняют свои размеры.

Исправлена гонка кнопки «Стоп»: поздние события закрытого плеера больше не оставляют большой пустой блок. Проверены два полных цикла воспроизведения и остановки в настоящем Telegram через MCP.

Для зависших публичных фотографий X добавлено ограниченное восстановление конкретного изображения с очисткой при смене страницы или источника. Системные VPN/DNS и общая стратегия прокси не менялись. Доступность публикаций по-прежнему зависит от провайдера и сети.

Встроенные Whisper, многоязычная модель, VAD и необходимые DLL остаются внутри установщика. Python и отдельная загрузка модели не нужны.

Визуальное сравнение находится в [review.html](../release/1.2.3/ui/review.html); изображения в нём используют синтетические данные. Точные результаты и границы проверок — в [аудите](AUDIT-1.2.3.md).

Сборка принята: TypeScript, ESLint, стили, frontend и NSIS прошли проверки. Изолированная установка, запуск, русская офлайн-транскрибация, подтверждённая отмена, штатный выход и удаление проверены; 15/15 критериев установщика пройдены. Формы отправки из X и Instagram проверены без отправки сообщений. YouTube может требовать нажатия Play.
