# Аудит Egoist Relay 1.1.0

Дата: 26 сентября 2026. Проект: `C:\Users\Egoist\Desktop\Проекты\Приложения\Egoist Relay`.

## Исходное состояние и область

Обнаружен Tauri 2 desktop fork Telegram Web A с X и Instagram в дочерних WebView2. Изучены история Git, существующие незакоммиченные изменения, документы релизов 1.0.1–1.0.5, транспорт, загрузка/выгрузка медиа, хранение, интерфейс и установщик. Пользовательские изменения сохранены; зависимости не добавлялись. Отдельная проверка затронула качество проекта, passcode/IndexedDB и просмотр документов.

Старые документы содержали утверждения о скорости, собственном DNS/DoH и универсальном обходе блокировок, которые исходники и измерения не подтверждают. Этот релиз описывает проверенное поведение и не повторяет эти обещания.

## Сетевой контракт

По умолчанию используются `127.0.0.1:1443` (MTProto), `1444` (WS bridge) и `1080` (DPI SOCKS). Встроенный Node.js не зависит от PATH пользователя. Bridge обслуживает Telegram API и media DC, а не X/Instagram. SOCKS/DPI-прокси обслуживает социальные WebView2. Relay не изменяет DNS, proxy, firewall или VPN Windows. Отдельного DNS-сервера/DoH-демона в приложении нет.

Порядок proxy overrides для social WebViews: `EGOIST_RELAY_X_PROXY` / `EGOIST_RELAY_INSTAGRAM_PROXY`, затем `EGOIST_RELAY_PROXY`, затем стандартные `HTTPS_PROXY`, `HTTP_PROXY`, `ALL_PROXY`, затем встроенный SOCKS. Допустимы HTTP(S)/SOCKS URL; недопустимые схемы, path и credentials отклоняются. Пользовательские пароли в URL не записываются в диагностические сообщения. Настройки читаются при создании WebView; смена переменных окружения требует перезапуска.

Статус «готово» означает доступность локальных протоколов. Для SOCKS проверяется реальное greeting; для bridge — версия протокола, ожидаемый TG-порт и формат транспорта. Собственная связь bridge → TG использует Intermediate E без transport padding; для внешнего настроенного proxy сохранён Padded D. Реальный unauthenticated `req_pq` подтвердил исправление ответа с 126 дополнительными padding bytes. Сторонний listener не завершается; неизвестный listener на занятом порту даёт ошибку. Известный внешний Telegram proxy используется только с подходящей конфигурацией/секретом. Перезапуск из интерфейса завершает и запускает собственные службы Relay. Supervisor восстанавливает их после сбоя.

WebView2 использует отдельные production-папки: main — `%LOCALAPPDATA%/com.egoist.relay`, X — дочерняя `x`, Instagram — `instagram`. Их расположение не менялось; миграции аккаунтов не проводились. Popup наследует environment opener. Remote-страницы не получают привилегии main Tauri IPC.

Официальный Wry callback `PageLoadEvent::Finished` в установленной версии WebView2 backend не доказывает успешность HTTP/network load. Проверять внешний сервис только по этому событию нельзя. Смена системного VPN/DNS при работе с реальным аккаунтом остаётся отдельным сценарием проверки.

Для зависшей страницы выполнено сравнение A–B–A–B на одном EXE и тех же авторизованных профилях без диагностического TCP-посредника. Прежняя стратегия дважды оставила Instagram без элементов интерфейса; объединённая дважды загрузила ленту и позволила прокрутку. Второй отказ прежней стратегии произошёл после успешной загрузки кандидата: улучшение нельзя объяснить только прогревом кеша. Проверена и окончательная сборка со встроенным прокси на 1080: X и Instagram загрузились, восстановились после штатного переподключения и снова загрузились после полного перезапуска с сохранёнными профилями. Это проверка на текущей сети, а не гарантия доступности всех CDN.

## Интерфейс и функции

Сохранена монохромная Egoist-палитра. Добавлены понятные русские подписи, иерархия текста, центрированные service states, навигация соцсетей и индикация локальных служб. Статус скачивания сообщает сервис и имя файла; имена не сталкиваются при повторных скачиваниях. Sidebar поддерживает клавиатуру, aria-current и aria-pressed. Убраны широкие анимации `transition: all`; reduced motion отключает необязательное движение и завершает переходы с очисткой предыдущего экрана.

Проверены реальные компоненты App в headless WebView-макете на 1652×1160, 1000×760 и 800×560: без пересечений titlebar/content и горизонтального переполнения. Минимальный размер native-окна 800×560 сохранён. Девять screenshot evidence входят в релиз. Производительность не выражается вымышленными «0 ms» или «3–5×»: доказаны конкретные изменения буферов, фонового видео, observer и размера сборки.

Дополнительно проверены переходы двадцати состояний настроек на реальных компонентах с тестовым Telegram-клиентом: прямое/обратное движение и уменьшенная анимация оставляют один активный экран. Это проверка интерфейса, а не серверного сохранения параметров. В существующем авторизованном профиле через API открыты десять разделов настроек Telegram и проверена прокрутка; аккаунт, пароль, приватность и активные сеансы не менялись.

Для проверки создан отдельный проект `Инфраструктура/Egoist Relay Control MCP` и skill `egoist-relay-control`. Adapter привязан к PID, времени запуска, executable, профилю и точному WebView target. Управление проходит через typed API, без мыши, клавиатуры и clipboard рабочего стола. Режим включается только при контролируемом запуске; обычный запуск не открывает debug endpoint. Замеры фонового режима подтверждают отсутствие активации окна Relay и изменений clipboard. Пользователь параллельно двигал мышь, поэтому неподвижность курсора не заявляется.

Удалена неработающая offline Whisper facade; она вызывала заглушку Rust после полной загрузки аудио. Telegram voice transcription сохранена с исходными premium/group-условиями. Пользователь не видит обещание функции, которая фактически отсутствует.

## Проверки

Машинные отчёты с source hashes находятся рядом с установщиком:

- `network-verification.json`: native process lifecycle, handshake, MTProto bridge framing и cleanup.
- `network-social-verification.json`: сравнение прежней и объединённой proxy-стратегий, полный ответ публичного JS, холодный запуск окончательной сборки и переподключение.
- `telegram-verification.json`: transport/read/codec/download/range/cancellation проверки, включая сравнение с исходными ошибками.
- `social-verification.json`: 32 headless integration cases для X/Instagram enhancers, security и media lifecycle.
- `persistence-verification.json`: 24 проверки IndexedDB, crypto, migration и очередей passcode.
- `ui/ui-evidence.json`: взаимодействия, доступность, reduced motion и 9 скриншотов.
- `ui/telegram-settings/interaction-matrix.json`, `sidebar-service-binding.json`: состояния настроек, завершение переходов и привязка боковой панели к сервисам.
- `native-verification.json`, `installer-verification.json`, `release-manifest.json`: окончательная native/packaging проверка и контрольные суммы.

`npm run check:ts` проходит без ошибок; остаются два предупреждения о deliberate HTML renderer в DocumentReaderModal, для которого проверены escaping cases. `npm run check:css` проходит без ошибок с 508 предупреждениями browser baseline/selector conventions. Они не скрывались как ошибки успешной проверки. Production сборка исключает `.map`; frontend уменьшен примерно с 221 MB до 199 MB. Ни installer size, ни frontend size не равны измерению потребления RAM.

В реальных X и Instagram короткие образцы rAF по 1,5 секунды дали median 16,7 мс, p95 16,8 мс и ноль наблюдавшихся long tasks. Renderer сообщал visible; замеры не заменяют проверку всех переходов и длительной работы. У отдельного MCP 17 строго типизированных инструментов; подтверждены привязка к процессу/профилю, запрет кнопок управления native-окном, отказ старой сессии и явное подключение новой после перезапуска. Исторические отчёты сохраняют исходные хэши; manifest отдельно показывает их соответствие окончательным исходникам.

## Оставшиеся ограничения

- Авторизованные профили использованы для чтения интерфейса и навигации. Нет подтверждения отправки сообщений, публикаций, многогигабайтных upload/download, передачи файлов через реальные media DC/CDN и всех географических блокировок. Неавторизованный MTProto handshake и реальный экран QR также проверены. Универсальный download любого поста/видео X/Instagram не реализован.
- На некоторых загрузках Instagram наблюдался anonymous TypeError при рабочей ленте; происхождение не установлено. Во время reload/переподключения возможны отменённые запросы; в одном кандидатном прогоне два запроса video.twimg завершились CONNECTION_CLOSED. Локальный HTTP/1.1 fixture с Connection: close выявил периодический короткий хвост ответа ciadpi, тогда как наблюдавшиеся HTTP/2 ответы были полными. Эти ограничения не объявлены устранёнными.
- Отменённая загрузка не выдаёт частичный файл как успех, но прогресс не сохраняется для продолжения после полного закрытия Relay.
- Telegram API credentials сохранены. Ранее встречавшийся `API_ID_PUBLISHED_FLOOD` не является результатом финальной проверки: чистый native-профиль получил настоящий QR. При повторном возникновении серверного ограничения оно требует отдельного решения на стороне credentials/API; обход ограничений аккаунта не выполнялся.
- Штатная смена системного VPN/DNS и переключение физической сети с активной передачей требуют отдельной живой проверки. Локальные службы следуют сетевому маршруту ОС; гарантия любых VPN отсутствует.
- Очередь passcode действует в пределах окна. Одновременная смена ключа в нескольких живых окнах отдельно не подтверждена.
- Document reader сохраняет отдельные UX-ограничения: поиск зависит от формата; перечень распознаваемых расширений шире полноценно поддерживаемых renderer. Проверены безопасность переключения и escaping, а не универсальная поддержка офисных форматов.
- Native installer проверяется в отдельной копии с тестовыми registry/protocol names; обновление поверх реальной установки и пользовательских аккаунтов не выполняется. Автообновление/публикация релиза не включались.
- Dev UI fixture фиксирует диагностические предупреждения initial GSAP style mutation; необработанных page errors в этой проверке нет. Это не утверждение об отсутствии всех возможных runtime warnings.

Итоговая поставка — проверенный локальный Windows installer и исходники с конкретными исправлениями. Внешние сервисы, сеть и условия аккаунтов остаются за границами локального healthcheck.
