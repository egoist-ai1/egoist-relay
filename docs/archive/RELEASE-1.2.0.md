# Egoist Relay 1.2.0

Windows x64, Tauri 2 / WebView2. Версия продолжает исправления транспорта, хранения, интерфейса и установщика из [1.1.0](RELEASE-1.1.0.md).

## Медиа внутри Telegram

Ссылки на YouTube Shorts и обычные ролики, Instagram Reels / посты и X получают встроенную карточку в сообщении. Нажатие открывает проигрыватель в этой карточке. Если Telegram уже предоставил собственное видео или аудио в preview, используется штатный проигрыватель Telegram.

При нескольких ссылках открывается именно выбранная. Исправлен старт карточки до первого измерения её видимости и ложное уведомление об обновлении из-за старого локального номера версии.

YouTube учитывает настройки автозагрузки / автовоспроизведения, видимость сообщения и reduced motion. Одновременно автоматически воспроизводится один ролик, без звука. При прокрутке за пределы экрана, смене сервиса или скрытии приложения встроенный проигрыватель освобождается. Ссылки без серверного preview загружаются по нажатию.

Instagram и X используют встроенные страницы своих платформ; для начала воспроизведения может понадобиться нажатие внутри карточки. Приватные, удалённые и запрещённые для встраивания публикации могут быть недоступны. Ошибка загрузки показывает повторную попытку; загрузка страницы не выдаётся за подтверждение воспроизведения.

## Поделиться в Telegram

На доступных публикациях X и Instagram появляется кнопка «Поделиться в Telegram». Она открывает выбор получателя поверх текущего сервиса. Переходить в Telegram и открывать чат не требуется.

Можно отправить текст со ссылкой либо добавить доступные фото и видео. Сначала приложение целиком подготавливает все выбранные файлы, затем отправляет их через существующий Telegram API. Файлы проходят через встроенный прокси. Успех показывается после подтверждения Telegram. При частичной ошибке повторяются только неподтверждённые сообщения с прежними идентификаторами.

Сохраняются текущий сервис, выбранный получатель и черновики чатов. Учитываются ограничения получателя и платные сообщения. Отправка требует явного нажатия пользователя. Во время отправки окно остаётся открытым; подготовку файлов можно отменить.

Ограничения подготовки: до 10 файлов, 64 MiB на файл и 128 MiB на публикацию. Список берётся из загруженной карточки публикации; все элементы ещё не загруженной карусели не гарантируются. Потоковые blob / HLS, истёкшие ссылки и медиа, которые источник не предоставляет как доступный файл, могут быть недоступны. Ошибка файла не приводит к незаметной отправке одной ссылки.

## Поставка и проверка

Установщик: `release/1.2.0/EgoistRelay_1.2.0_x64-setup.exe`. Он включает локальные службы, Node.js и офлайн-пакет WebView2. Обычный запуск не включает диагностический endpoint. Системные настройки DNS, VPN и прокси Windows не изменяются.

Если внешний прокси недоступен уже при запуске, основной интерфейс и локальный Telegram-мост остаются доступны, а удалённые iframe блокируются. После устранения причины требуется перезапуск приложения для настройки маршрута основного WebView.

Объём проверок и оставшиеся ограничения описаны в [аудите](AUDIT-1.2.0.md). Машинные отчёты и контрольные суммы находятся в `release/1.2.0`. Проверки версии 1.1.0 сохранены со своими исходными хэшами.
