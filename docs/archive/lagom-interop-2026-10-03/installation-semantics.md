# Relay 1.4.6 — штатное завершение, установка и фоновый запуск

Срез исходников от 3 октября 2026 года. Этот документ описывает доступные механизмы; он не подтверждает выполнение установки или выхода из текущего экземпляра.

Штатное завершение выполняет `app.exit(0)`: пункт tray `quit` в `tauri/src/tray/mod.rs:77`. Уже установленный plugin-process предоставляет тот же путь через локальный main WebView: `window.__TAURI_INTERNALS__.invoke('plugin:process|exit', { code: 0 })`. Команда подключена в `tauri/src/lib.rs:214`, capability `process:default` в `tauri/capabilities/default.json:35` разрешает `allow-exit`. Фактические версии локальных источников plugin-process: Rust2.3.1 и соответствующий `node_modules/@tauri-apps/plugin-process/dist-js/index.js`; аргумент называется `code`. RunEvent::Exit в `tauri/src/lib.rs:337` закрывает принадлежащие Relay workers. Этот API можно использовать только через уже доступный точный локальный main WebView; research named pipe запрещает eval и не имеет quit-operation. Подтверждённого CLI `--quit` нет. WM_CLOSE скрывает окно и сохраняет процесс.

Capability default.json и tray/mod.rs совпадают с freeze опубликованного1.4.6: SHA256 соответственно `20ccf1968ff4cb407f3c4691f2a824c83b65b19f524eb6e808ee2481c53a8d85` и `041552958ed381f0fecaf6ea06dc509abc04e918953ea378e8e25a8250fb7cd2`. Изменённые участки lib.rs не меняют подключение plugin-process или RunEvent::Exit.

Полный штатный Setup сохраняет NSIS currentUser, русский интерфейс, x64/Windows10 1903+, LZMA, original icons/header/sidebar, offlineInstaller WebView2 minimum143.0.0.0, updater OFF и 40 исходных runtime-файлов. `tauri/installer.nsh` вызывает проверку выбранной папки и версии до установки, блокирует downgrade, а штатный scoped process hook возвращает RELAY_EXIT_REQUIRED/exit2, если главный Relay ещё запущен. Hook не завершает главную программу. Он завершает лишь оставшиеся workers по точным путям и сверенным PID/времени старта внутри выбранной папки Relay. Legacy cleanup удаляет только перечисленные обычные файлы внутри runtime этой папки с совпавшими размером и SHA256; системные службы, DNS, маршруты, адаптеры и папка Lagom туда не входят. Установка и удаление этой сборки не запускались этим агентом.

Новая опция `--start-hidden` задаёт visible=false/focus=false до создания окна (`lib.rs:158`, `:489`) и не выводит существующий экземпляр на передний план. Это обычный фоновый старт, без режима EGOIST_RELAY_CONTROL_MODE=background, который блокирует пользовательское восстановление окна. Tray Open остаётся доступным. Файл ручного ярлыка можно создать в штатной per-user Startup папке с target точного установленного EXE, argument `--start-hidden`, working directory папки установленного Relay. Это рекомендация для Root; данный аудит не изменяет Startup/Run/задачи/службы. Повторный запуск по обычному ярлыку без hidden-флага открывает существующий экземпляр. Функциональную проверку реального фоново запущенного экземпляра следует фиксировать после авторизованной установки.

Private handoff `%LOCALAPPDATA%\EgoistRelay\interop\lagom-telegram.json` является отдельными данными пользователя вне `%LOCALAPPDATA%\Egoist Relay` с пробелом, где располагается бинарный payload. NSIS legacy cleanup и обычный payload его не включают. Авторитетные данные пользователя/аккаунтов в установщик не включаются.
