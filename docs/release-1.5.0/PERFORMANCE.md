# Сопоставимые измерения интерфейса

6 октября 2026. Три чередующиеся запуска 1.4.7 и 1.5.0: одинаковые MockClient-данные, FullHD, Edge 154, запрет внешних запросов. Исходная версия загружается из сохранённых исходников рабочего дерева, а не из старого Git HEAD.

Перед измерением: шесть переключений сервисов, два цикла модального окна и готовность шрифтов. Измеряем: 48 переключений и 24 открытия/закрытия модального окна в каждом запуске. В задержку включены click, подтверждение выбранного сервиса и два animation frame.

| Метрика: медиана трёх запусков | 1.4.7 | 1.5.0 | Изменение |
| --- | ---: | ---: | ---: |
| Задержка переключения | 61.13 мс | 60.76 мс | -0.60% |
| p95 задержки переключения | 81.50 мс | 63.67 мс | -21.87% |
| 48 переключений | 3115.61 мс | 2874.12 мс | -7.75% |
| CPU дерева Edge за сценарий | 6.25 с | 5.59 с | -10.50% |
| Private bytes дерева Edge | 717.00 МиБ | 708.89 МиБ | -1.13% |
| Максимум private bytes среди трёх замеров | 737.98 МиБ | 738.36 МиБ | +0.05% |
| JS heap | 65.79 МиБ | 66.97 МиБ | +1.79% |

Регрессии больше 10% вне наблюдаемого разброса трёх повторов не обнаружено. Диапазоны CPU и памяти пересекаются: это подтверждает отсутствие обнаруженного ухудшения в данном сценарии, но не доказывает ускорение продукта на всех устройствах.

CPU и private bytes сняты через Get-Process для всего отдельного дерева Edge. Короткоживущие процессы между тремя выборками могли не попасть в сумму; измерения private bytes не являются непрерывным максимумом. На первом холодном старте Vite исходной версии были ошибки preload main bundle до границы измерения. Холодный запуск, дерево процессов установленного Tauri/Relay, live-сервисы и физические GPU/DPI этим сравнением не проверены.

После замеров исправлен только native путь отказа журнала при Requested; измеренный код интерфейса не менялся.
