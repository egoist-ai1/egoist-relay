# Sennit 1.8.0 (бывший Egoist Relay)

8 октября 2026, ветка `lagom-redesign`. Отчёты по частям — `docs/lagom-redesign-2026-10-07/`.

## Что нового по сравнению с 1.7.1

- **Фирменный установщик `Sennit-Setup-1.8.0.exe`** — своё безрамочное окно Lagom (тёмная и светлая тема), этапы и статус-бар, кнопки «Установить» / «Запустить Sennit», журнал, тихий режим `--silent`. Внутри — проверенный NSIS-установщик Tauri (запускается тихо), SHA-256 проверяется до запуска. Независимое ревью (Fable) закрыто: подмена DLL, зависание без WebView2, сторож NSIS, подпись, атомарная запись. [INSTALLER](lagom-redesign-2026-10-07/INSTALLER.md)
- **Фронтенд.** Кнопка создания — строгий круг цветом Lagom (причина овала: `min-height` 3rem против ширины 2.25rem); знак Sennit в rail, на входе и в QR; брендовый пустой экран; исправлена тонкая отрисовка знака (атрибуты `stroke-width`); нет белой вспышки при старте; плоский фон вместо обоев Telegram за колонкой; монохромный спиннер соединения. Вход: запросов 52 → 44, передано 4753 → 2380 КБ. [FRONTEND-FINAL](lagom-redesign-2026-10-07/FRONTEND-FINAL.md)
- **Сеть.** Гонка маршрутов Lagom / прямой, backoff с джиттером, адаптивный ping-таймаут, пробуждение по `online`, перезапуск воркера моста с ростом паузы; X и Instagram прогреваются лениво (после готовности Telegram и простоя), настройка и строка маршрута с пингом в Настройки → Общие → Сеть. [NETWORK](lagom-redesign-2026-10-07/NETWORK.md)
- `public/build-stats.json` и `statoscope-report.html` вынесены из Git.
