# Egoist Social 1.9.8 — статус кандидата

## Изменения

- Все сообщения и медиа Telegram продолжают идти через собственный локальный TG-прокси. Для медиа используется H2, для остального Telegram-трафика — WebSocket; Cloudflare domain pool выбирается автоматически без жёсткой привязки к одному домену. A/B менял только media-маршрут. X и Instagram остаются на прежнем маршруте.
- TG engine source обновлён до v1.11.2 (`307a384...`). Headless-сборка включает root-патч: CF H2 pool, до 5 параллельных соединений, тайм-аут быстрой стадии 2 секунды, per-DC lock выбора маршрута и повторное использование/очистку соединений. При отсутствии быстрого ответа сохраняется прежний последовательный fallback с тайм-аутом 10 секунд; при отмене или ошибке relay handshake соединение закрывается.
- Runtime использует H2 multiplexing для медиа; WS redirect через указанный IP применяется только для DC4.
- Пользователь дважды подтвердил, что media-only A/B с полным domain pool заметно быстрее, затем подтвердил: «Да, всё быстро».
