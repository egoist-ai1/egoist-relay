# Egoist Social 1.9.9

Кандидат по итогам аудита 17.10.2026 (ветка `audit-fixes-2026-10-17`, 20 коммитов поверх 1.9.8, `71097db..HEAD`).

## Что изменилось

- Сеть и туннель: Xray API перенесён с открытого TCP на приватный unix-сокет (с коротким запасным каталогом в ProgramData); обновление подписки вынесено из-под блокировки CORE, короткие повторы, без лишнего перезапуска Xray; RAII-guard флага обновления и явный результат `REFRESH_BUSY`; плавающий узел, фокус не сбрасывает серии проб, шум проб убран из журнала; ошибка запуска видна в статусе.
- Telegram: проверка владельца локального порта прокси (чужой слушатель — повтор); пересоздание зависшего экспортного sender при таймауте, 15 с на малые части; диагностика stderr tg-ws-proxy и причины выхода curl при загрузке подписки.
- tg-ws-proxy 1.11.2-social.2: патч h2-liveness (таймаут первого байта 15 с, H2 PING 12/5 с, экспоненциальный backoff линий 5 до 60 с), WS-fallback при долгих банах линий, жизнеспособность по потоку, тихие таймауты повтора.
- X/Instagram: прогрев аккаунта без проб при входе/проверке безопасности, backoff, проба не держит окно; блок прогрева снимается, когда основное окно готово.
- Исследование: стабильный `accountRef` из аккаунта; постоянные ошибки адреса остаются `UNSUPPORTED`, PEER_FLOOD/деактивация дают `ACCOUNT_RESTRICTED`, неизвестные ошибки платформы — повторяемые `PLATFORM_ERROR`; скользящий срок кэша пиров с потолком 7 суток; сброс backoff проб только при снятии блока владельца.

## Предупреждения

- Живой трафик новых сетевых изменений (Xray на сокете, tg-ws-proxy social.2) не проверялся.
- Во фронтенде у результата `REFRESH_BUSY` нет текста для пользователя.
- Установка и запуск установщика в этой сессии не выполнялись.
