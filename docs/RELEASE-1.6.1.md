# Egoist Relay 1.6.1

Windows x64, предварительный выпуск.

- Панель загрузок и пересылок: доступные результаты, локальная история, отмена и ручной повтор, форматы «Ссылка / Медиа / Файл».
- Единая чёрная и серая оболочка; исправлены прозрачные меню, наложения и перенос коротких подписей.
- Telegram Mini Apps и дочерние окна размещаются в собственных WebView2 с той же сетевой средой и ограниченным native bridge.

Готовый установщик опубликован без пересборки: 567488354 bytes, SHA-256 3066963d99430ffa83a3b62c1f1c29e4db8b6040846932fd1bd9bfae8d121751.

Точечные проверки hotfix: 7 сценариев интерфейса, 7 адаптерных и 4 SDK-проверки, 3 native guard-проверки; основной TypeScript, затронутые ESLint/Stylelint, Vite, Rust, NSIS и preflight прошли. Проверки интерфейса использовали синтетические данные; guard harness не заменяет native COM-проверку. Полные тесты повторно при публикации не запускались.

Установщик без цифровой подписи, updater отключён. Живые аккаунты, native PAC/окна, DPI/GPU и установка на чистой машине не приняты. Полнота исходников зависимостей не заявляется; подробности в dependency-sources.json.
