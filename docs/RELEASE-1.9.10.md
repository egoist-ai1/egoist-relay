# Egoist Social 1.9.10

Исправление поверх 1.9.9 (коммит `6c36325`).

## Что исправлено

- Туннель 1.9.9 не стартовал: на машине владельца сокеты AF_UNIX в `%LOCALAPPDATA%` / `%APPDATA%` создаются, но не принимают соединений (WSAEINVAL) и не открываются и не удаляются (ошибка 1920). Прежний код считал Xray готовым по наличию файла сокета, а недоступный остаток давал вечный `TUNNEL_API_SOCKET_BUSY`.

## Новое поведение

- Имя сокета Xray API уникально на каждый запуск (`api-<роль>-<hex>.sock`), путь подставляется в конфиг при старте; остатки прошлых запусков удаляются по возможности, отказ (1920) не фатален.
- Готовность Xray проверяется настоящим `connect` к сокету, а не наличием файла.
- Каталог для сокета выбирается пробой AF_UNIX (bind и connect); запасной вариант — каталог в ProgramData.

## Предупреждения

- Живой трафик через туннель и новый Xray API не проверялся; установка и запуск установщика не выполнялись.
- Прочие предупреждения 1.9.9 в силе: `REFRESH_BUSY` без текста во фронтенде; tg-ws-proxy 1.11.2-social.2 на живом трафике не проверялся.
