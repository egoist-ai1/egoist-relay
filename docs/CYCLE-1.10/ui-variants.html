Четыре направления интерфейса Egoist Social 1.10

макет · 24.10.2026
Один сценарий для всехУтро. Telegram открыт на чате с Мариной, X уснул два часа назад, Instagram потерял вход. Нужно найти «бриф» во всех сервисах и следить за сохранением видео.
Реальные данныеПамять 1,8 ГБ и 22 процесса WebView2 — замер 24.10. Туннель, узел 3 из 47 — журнал 23–24.10.
ИллюстрацияИмена чатов, файлы, проценты загрузки и список событий придуманы для макета. Всё остальное в пределах Lagom: монохром, без акцента.

Кадры кликабельны: в A — иконки rail и плашки состояния, в B — Ctrl+K или кнопка поиска, ↑↓ и Esc, в C — кнопки на карточках, в D — фильтры. Действия не выполняются: это макет, а не работающее приложение. Все четыре кадра показаны в одном масштабе и с одинаковыми данными.

A · эволюция

Тихая рамка+

Оболочка почти не меняется. В строку заголовка добавляется живое состояние: сеть, память, операции. Rail честно показывает сон и потерю входа, а вместо пустой страницы сервис объясняет причину и даёт следующий шаг.

Плюсы
Привычный вид, минимум риска, закрывает «вход слетел» и видимость сна.
Минусы
Новых сценариев не даёт: поиск и сохранённое остаются как есть.
Цена
Низкая: 1–2 недели, только фронтенд и несколько событий из Rust.
B · поиск

Палитра команд

Ctrl+K открывает единую строку: поиск по Telegram, сохранённому из X и Instagram, плюс действия — разбудить сервис, сохранить медиа, открыть операции. Для Instagram с потерянным входом палитра ищет только по сохранённому и говорит об этом.

Плюсы
Закрывает потребность «единый поиск», быстро для клавиатуры, оболочка не растёт.
Минусы
Нужен локальный индекс (SQLite FTS5); поиск в живом X и Instagram запрещён их условиями и риском для аккаунта.
Цена
Средняя: индексатор, хранилище, приватность индекса.
C · статус

Пульт сервисов

Первая вкладка rail — домашний экран: три сервиса со состоянием и действием, сеть, память, очередь операций, короткий журнал. Приложение объясняет, что с ним происходит, вместо того чтобы молчать и тормозить.

Плюсы
Прозрачность ресурсов и сети, место для диагностики моста Telegram, удобно для проверки цикла.
Минусы
Лишний экран: ежедневно владельцу нужен Telegram, а не пульт.
Цена
Средняя: сбор метрик по сервисам, события, новый экран.
D · функции

Библиотека как четвёртый раздел

Сохранённое из трёх сервисов собирается в одном месте: сетка, фильтры по сервису и типу, поиск по подписям и именам, очередь загрузок снизу. Ctrl+J остаётся быстрой панелью, а библиотека превращается в постоянный раздел.

Плюсы
Даёт новую ценность: «сохранил и нашёл», пакетная очередь, дедупликация.
Минусы
Самый объёмный: хранилище, миниатюры, перенос уже сохранённых файлов.
Цена
Высокая: 4–6 недель, нужны решения по формату хранения.
