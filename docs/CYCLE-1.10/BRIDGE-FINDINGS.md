## Дефекты диагностики [проверено по коду и журналу]

1. `ProxyLogFilter` пускает любые строки со словом `error`/`warn`, поэтому обычные INFO-закрытия сессий («DC2 WS session closed (upstream: ConnectionResetError)») попадают в журнал на уровне WARN.
2. Лимит `PROXY_LOG_LINES = 20` за запуск прокси съедается всплеском одинаковых строк: 16 × «DC2 CF proxy failed: gaierror(11001)» за одну секунду 18.10 12:46:23 и 22.10 14:48:42. Оба всплеска совпадают с отказом DoH 1.1.1.1 в Xray — то есть с сетевым провалом, а не ошибкой моста.
3. Строка при выходе не содержит время жизни, число полученных строк stderr, состояние второго процесса и сна — различить «убит извне / упал сам / штатный выход» по ней нельзя.
4. При штатном закрытии приложения воркер пишет WARN о «выходе» (случай 12:33).

## Коды выхода Windows (как читать новую строку)

| Код | Что значит |
|---|---|
| 1 | `TerminateProcess(…,1)`, `taskkill /F`, `Child::kill` или собственный `exit(1)`; при пустом stderr — завершение извне |
| 0xFFFFFFFF (−1) | `Stop-Process` / .NET `Kill` |
| 0x40010004 | завершение сеанса или выключение Windows |
| 0xC000013A | Ctrl+C / закрытие консоли |
| 0xC0000005, 0xC0000409 | падение процесса (нарушение доступа, сбой стека) |
