# Egoist Relay 1.0.1

**Сборка форка с существующими параметрами Telegram.** Новое API-приложение не регистрировалось по решению владельца. При проверке текущих Telegram API credentials получен `API_ID_PUBLISHED_FLOOD`; успешное получение QR в другом прогоне не отменяет риск отказа авторизации со стороны сервера.

## Исправления

- Telegram и X используют постоянные представления. Переключение сериализовано, ошибки нативного окна не теряются. Добавлены понятные loading/error/retry состояния, клавиатурный фокус и локализованные подписи.
- После создания X главное окно остаётся доступным для трея, уведомлений, ссылок и оконных команд. Создание WebView выполняется вне блокирующего обработчика UI Windows.
- Node.js и локальный Telegram-прокси входят в установщик. Ресурсы находятся в `runtime/`; для release не используются пути компьютера разработчика или Node.js из PATH.
- Сетевой мост ограничивает очереди, учитывает обратное давление, отклоняет посторонние origins, корректно завершает неудавшееся подключение и очищает обработчики. При выходе завершается только собственное дерево процессов.
- Установщик использует штатную установку и удаление Tauri/NSIS. Удалены глобальные `taskkill /IM`, преждевременное удаление бинарников и рекурсивная очистка других установок.
- Legacy-установка проверяет наличие runtime и Whisper, результат распаковки и создания ярлыков. Пути со спецсимволами передаются в PowerShell как данные.
- Основной шрифт возвращён к 16 px; обычный жирный текст не меняет гарнитуру. Анимации учитывают reduced motion и отменяются при размонтировании.
- Устранён условный вызов хука в области перетаскивания файлов. В просмотрщике документов экранируются URL-атрибуты, блокируются исполняемые URL, ограничивается распаковка DOCX.
- Передача файлов использует настоящий Premium-статус аккаунта. Локальная подмена Premium не снимает серверные ограничения и в этой сборке не применяется.

## Проверка

TypeScript и целевые проверки ESLint/Stylelint прошли. Impeccable не обнаружил проблем в изменённых компонентах хаба. Проверены HTML-инъекция, опасная Markdown-ссылка, корректная HTTPS-ссылка и ссылка с кавычками.

В изолированном WebView2-профиле X загрузил настоящую страницу входа. Проверены повторное использование единственного X WebView, запрет привилегированных команд из X, отклонение неизвестного приложения и небезопасного внешнего URL. Учётные записи пользователя не использовались.

В headless Edge проверены экраны 1280×820 и 800×560, повторное переключение и сообщение о затянувшемся подключении. Горизонтального переполнения и ошибок JavaScript на этих экранах не обнаружено.

Полные репозиторные команды lint не являются зелёными: остаются замечания в ранее добавленных модулях и конфигурации проверки служебных/сгенерированных файлов. Сборка и точечная проверка изменённых участков не заменяют тестирования всех функций Telegram на авторизованном аккаунте.

## Сетевые границы

MTProxy обслуживает Telegram. X использует системный маршрут WebView2. Произвольная блокированная сеть требует отдельного работающего маршрута для X; Relay не меняет глобальные DNS, firewall или настройки системного туннеля. Вход в Telegram и X остаётся действием пользователя.

Проверка `/health` подтверждает готовность локального моста, а не доступность Telegram или успешную авторизацию. Подробности окончательной проверки бинарника и установщика приведены в `VERIFICATION-1.0.1.md`.

В холодном сетевом прогоне подготовка резервного пула заняла около 8 секунд, MTProto-соединение установилось примерно на 10-й секунде. Это измерение одного окружения, не обещание времени подключения в любой сети. В другом прогоне подтверждено состояние `authorizationStateWaitQrCode` и наличие QR. Ошибка `API_ID_PUBLISHED_FLOOD` фиксируется отдельно от сетевых ошибок; её нельзя объяснять только частотой повторных проверок.

## Основания решений

- [Telegram Desktop](https://desktop.telegram.org/) и `design/references/selected-messenger-layout.png`: постоянная навигация, читаемый основной текст, сохранение контекста сообщений.
- [Официальные клавиатурные сценарии X](https://help.x.com/en/using-x/how-to-post): сохранение нативного интерфейса и поведения X во встроенном движке.
- [Tauri capabilities](https://v2.tauri.app/security/capabilities/): отдельная граница полномочий для удалённого X и локального интерфейса.
- [Telegram Premium API](https://core.telegram.org/api/premium): серверная природа Premium-ограничений скорости.
- [Регистрация Telegram API приложения](https://core.telegram.org/api/obtaining_api_id): собственный API ID для релиза и ограничение `API_ID_PUBLISHED_FLOOD`.

Подпись издателя и полная проверка отправки сообщений, звонков, больших файлов, нескольких аккаунтов и обновления существующей пользовательской установки в этой задаче не заявляются.
